# คู่มือติดตั้ง Telegram bot แจ้งเตือนจุดความร้อน (คู่ขนานกับ LINE)

ทำงานคู่กับบอท LINE เดิม (`docs/line-bot.md`) โดยไม่แตะกัน — ถ้า LINE ขัดข้องหรือโควตาหมด Telegram ยังแจ้งเตือนต่อได้

| ส่วน | ทำอะไร |
|---|---|
| แจ้งเตือนจุดใหม่ | ทุกรอบของ workflow `site` (~10 นาที): ถ้ามีจุดใหม่ในแนวเขต (สแกนไม่เกิน 12 ชม., **ไม่รวม ขสป.ดงใหญ่**) ส่ง 1 ข้อความรวมทุกจุด แยกตามพื้นที่อนุรักษ์ ท้ายข้อความมีตารางรายพื้นที่ สะสมปีงบนี้ เทียบทั้งปีงบก่อน (▲▼%) — ยอดปีนี้นับเฉพาะดาวเทียมตัวชี้วัด (NOAA-20) จุดจากดวงอื่นจึงแจ้งเตือนแต่ไม่เพิ่มยอด |
| สรุปประจำวัน | ทุกวัน 07:30 น. (เปลี่ยน/ปิดได้) — จุดใน 24 ชม., สะสมปีงบเทียบปีก่อน, รายพื้นที่, พื้นที่ที่พบมากสุด |
| พื้นที่เผาไหม้ | เมื่อระบบตามรอยเผาออกรอบใหม่ที่มีรอยเผา ≥ 1 ไร่ (ส่งแบบไม่มีเสียงเตือน) · ปุ่ม "ดูพื้นที่เผาไหม้บนแผนที่" เปิดหน้าเว็บที่ชั้นพื้นที่เผาไหม้ของรอบนั้นและซูมไปที่รอยเผา |
| แจ้งผู้ดูแลเมื่อระบบเสีย | (ไม่บังคับ) ส่งถึงคุณคนเดียว เหมือนข้อ 9 ของคู่มือ LINE |
| สถานะ | `https://takiang71.github.io/fire-map-dpky/tg_notify.json` (แยกจาก notify.json ของ LINE) |

**ต่างจาก LINE:**
- Telegram **ไม่มีโควตารายเดือน** ส่งเข้ากลุ่มกี่คนก็ได้ จึงไม่จำกัดจำนวนครั้งต่อวัน
- ข้อความเป็นตัวอักษร (Telegram ไม่มีการ์ดเลื่อนแบบ Flex) มีปุ่มใต้ข้อความ "ดูจุดบนแผนที่" (พาไปที่จุด/กรอบของจุดบนหน้าเว็บ) และ "แผนที่ไฟป่า"
- แต่ละจุด: เวลา (ตัวหนา) ดาวเทียม ตำบล/อำเภอ/จังหวัด สถานีฯ แล้วบรรทัดถัดไปเป็นลิงก์ **📍Google Maps** (นำทางไปที่พิกัด) และ **🔥แผนที่ไฟป่า** (เปิดรายละเอียดจุดบนหน้าเว็บ)
- ข้อความหนึ่งแสดงได้ราว 21–28 จุด (ปกติดาวเทียมรอบหนึ่งพบ 1–2 จุด สูงสุดปีงบ 2569 = 9) (พื้นที่ละไม่เกิน 20) เกินนั้นขึ้น "…และอีก N จุด" แต่ตัวเลขรวมนับครบ และปุ่ม "📍 ดู N จุด" ซูมให้เห็นทุกจุด
- บอทยังไม่ตอบคำสั่งพิมพ์ (เช่น "สรุป") — ส่งอัตโนมัติอย่างเดียว

## 1. สร้างบอท

1. ในแอป Telegram ค้นหา **@BotFather** (มีเครื่องหมายถูกสีฟ้า) → กด **Start**
2. พิมพ์ `/newbot`
3. ตั้งชื่อที่แสดง เช่น `Hotspots สบอ.1`
4. ตั้ง username ภาษาอังกฤษ ต้องลงท้ายด้วย `bot` เช่น `hotspots_sbo1_bot`
5. BotFather ตอบ **token** หน้าตาแบบ `1234567890:AAH...` — **ห้ามส่งให้ใคร ห้ามวางในแชต**

## 2. เก็บ token ใน GitHub (ไม่ต้องใช้ Terminal)

repo `takiang71/fire-map-dpky` → **Settings → Secrets and variables → Actions → แท็บ Secrets → New repository secret**
- Name: `TG_TOKEN`
- Secret: วาง token จากข้อ 1

## 3. พาบอทเข้ากลุ่ม แล้วหารหัสกลุ่ม

1. เปิดกลุ่ม Telegram ที่จะรับแจ้งเตือน → แตะชื่อกลุ่ม → **Add members** → ค้นหา username ของบอท → เพิ่ม
   - ถ้าใช้ **channel** แทนกลุ่ม: เพิ่มบอทเป็น **Administrator** ที่มีสิทธิ์ Post messages
2. พิมพ์ในกลุ่ม: `/start@hotspots_sbo1_bot` (ใช้ username ของบอทคุณ)
3. GitHub → แท็บ **Actions** → เลือก **tg-test** (ซ้ายมือ) → **Run workflow** → เลือก `chats` → **Run workflow**
4. รอ ~1 นาที กดเข้ารายการที่รันเสร็จ → **send** → เปิดขั้น `Run node scripts/telegram_notify.js --chats` จะเห็นบรรทัดแบบ
   ```
   TG_CHAT_ID = -1001234567890   (supergroup) ชื่อกลุ่ม
   ```
   ถ้าไม่พบห้อง ให้พิมพ์ในกลุ่มอีกครั้งแล้วรันใหม่ (บอทเห็นข้อความย้อนหลังแค่ 24 ชม.)

> repo เป็นสาธารณะ คนอื่นเห็น log นี้ได้ แต่รหัสกลุ่มอย่างเดียวส่งข้อความไม่ได้ (ต้องมี token ด้วย)

## 4. ตั้งรหัสกลุ่ม

**Settings → Secrets and variables → Actions → แท็บ Variables → New repository variable**
- `TG_CHAT_ID` = รหัสจากข้อ 3 (ใส่ในแท็บ Secrets ก็ได้ ระบบอ่านทั้งสองที่) (รวมเครื่องหมายลบ) · หลายห้องคั่นด้วยจุลภาค เช่น `-1001234567890,-1009876543210`
- (ไม่บังคับ) `TG_DAILY` = เวลาส่งสรุปประจำวัน เวลาไทย `HH:MM` (ไม่ตั้ง = 07:30 · `off` = ปิด)
- (ไม่บังคับ) `TG_BURN` = `off` ถ้าไม่ต้องการข้อความพื้นที่เผาไหม้

## 5. ทดสอบ

Actions → **tg-test** → Run workflow → เลือก
- `test-push` = ข้อความแจ้งเตือนตัวอย่าง (จุดจริงล่าสุด 5 จุด ติดป้าย 🧪 ทดสอบ)
- `daily` = สรุปประจำวัน · `burn` = พื้นที่เผาไหม้รอบล่าสุด
- `preview` = แสดงข้อความทุกแบบใน log โดยไม่ส่ง

แจ้งเตือนจริงเริ่มเองในรอบถัดไปของ workflow `site` — **รอบแรกจะไม่ส่ง** (บันทึกจุดที่มีอยู่ว่าแจ้งแล้ว กันส่งจุดเก่าทั้งชุด) รอบต่อไปส่งเฉพาะจุดใหม่

## 6. (ไม่บังคับ) แจ้งผู้ดูแลเมื่อระบบเสียทาง Telegram

1. ในแอป Telegram เปิดแชตส่วนตัวกับบอท กด **Start**
2. Actions → tg-test → `chats` → จะเห็นบรรทัด `(private)` ชื่อคุณ
3. Variables → `TG_ADMIN_ID` = รหัสนั้น (ตัวเลขบวก)

รอบถัดไปบอทส่ง "✅ ตั้งค่าแจ้งเตือนผู้ดูแลเรียบร้อย" มาให้ จากนั้นจะแจ้งเรื่องเดียวกับ LINE (API/sync/ระบบต้นทาง/หน้าเว็บหยุด) และเพิ่ม:
- **Telegram ใช้งานไม่ได้** เกิน 1 ชม. (token ผิด / บอทถูกเอาออกจากกลุ่ม)
- **กลุ่มถูกอัปเกรดเป็น supergroup** — Telegram เปลี่ยนรหัสกลุ่มเมื่อกลุ่มใหญ่ขึ้นหรือเปิดบางการตั้งค่า ระบบส่งไปที่รหัสใหม่ให้เองทันที แต่ให้แก้ `TG_CHAT_ID` ตามข้อความ

ตั้งทั้ง `LINE_ADMIN_ID` และ `TG_ADMIN_ID` = ได้ทั้งสองทาง (LINE เสีย/โควตาหมด ก็ยังรู้ทาง Telegram)

## ตรวจปัญหา

- **ไม่มีแจ้งเตือน:** เปิด `…/fire-map-dpky/tg_notify.json`
  - ช่อง `tg`: `ok: 1` = token ใช้ได้และบอทอยู่ในห้อง (มีชื่อห้อง/จำนวนสมาชิก) · `ok: 0` + `why` = เหตุผล · `off` = ยังไม่ตั้ง secret/variable
  - ช่อง `log` (ใหม่สุดก่อน): ส่งแล้ว (`ok` = จำนวนห้องที่ส่งได้) หรือข้ามเพราะอะไร
- **`403 Forbidden: bot was kicked`** = บอทถูกเอาออกจากกลุ่ม → เพิ่มกลับ
- **`400 Bad Request: chat not found`** = รหัสห้องผิด หรือบอทยังไม่ได้อยู่ในห้องนั้น
- **`401 Unauthorized`** = token ผิด หรือถูกเปลี่ยน (BotFather → /revoke) → แก้ secret `TG_TOKEN`
