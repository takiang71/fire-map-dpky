# คู่มือติดตั้ง Telegram bot แจ้งเตือนจุดความร้อน (คู่ขนานกับ LINE)

ทำงานคู่กับบอท LINE เดิม (`docs/line-bot.md`) โดยไม่แตะกัน — ถ้า LINE ขัดข้องหรือโควตาหมด Telegram ยังแจ้งเตือนต่อได้

| ส่วน | ทำอะไร |
|---|---|
| แจ้งเตือนจุดใหม่ | ทุกรอบของ workflow `site` (~5 นาที): ถ้ามีจุดใหม่ในแนวเขต (สแกนไม่เกิน 12 ชม., **ไม่รวม ขสป.ดงใหญ่**) ส่ง 1 ข้อความรวมทุกจุด แยกตามพื้นที่อนุรักษ์ ท้ายข้อความมีตารางรายพื้นที่ สะสมปีงบนี้ เทียบทั้งปีงบก่อน (▲▼%) — ยอดปีนี้นับเฉพาะดาวเทียมตัวชี้วัด (NOAA-20) จุดจากดวงอื่นจึงแจ้งเตือนแต่ไม่เพิ่มยอด |
| สรุปประจำวัน | ทุกวัน 05:30 น. (เปลี่ยน/ปิดได้) — จุดใน 24 ชม., สะสมปีงบเทียบปีก่อน, รายพื้นที่, พื้นที่ที่พบมากสุด, ดาวเทียมรอบถัดไป, อัตราระบายอากาศ (GFS), FWI (กรมป่าไม้), PM2.5 แบบจำลอง CAMS |
| พื้นที่เผาไหม้ | เมื่อระบบตามรอยเผาออกรอบใหม่ที่มีรอยเผา ≥ 1 ไร่ (ส่งแบบไม่มีเสียงเตือน) · ปุ่ม "ดูพื้นที่เผาไหม้บนแผนที่" เปิดหน้าเว็บที่ชั้นพื้นที่เผาไหม้ของรอบนั้นและซูมไปที่รอยเผา |
| **แจ้งเตือนรายพื้นที่ (ส่วนตัว)** | เจ้าหน้าที่พิมพ์ `/ตาม ทับลาน` ในแชตส่วนตัวกับบอท → ได้ข้อความแจ้งเตือนจุดใหม่**เฉพาะพื้นที่ที่เลือก**ถึงตัวเอง (รูปแบบเดียวกับข้อความกลุ่ม · สมัคร ขสป.ดงใหญ่ ได้) — ดู [คำสั่งสำหรับเจ้าหน้าที่](#คำสั่งสำหรับเจ้าหน้าที่-แจ้งเตือนรายพื้นที่) |
| แจ้งผู้ดูแลเมื่อระบบเสีย | (ไม่บังคับ) ส่งถึงคุณคนเดียว เหมือนข้อ 9 ของคู่มือ LINE |
| สถานะ | `https://takiang71.github.io/fire-map-dpky/tg_notify.json` (แยกจาก notify.json ของ LINE) |

**ต่างจาก LINE:**
- Telegram **ไม่มีโควตารายเดือน** ส่งเข้ากลุ่มกี่คนก็ได้ จึงไม่จำกัดจำนวนครั้งต่อวัน
- ข้อความเป็นตัวอักษร (Telegram ไม่มีการ์ดเลื่อนแบบ Flex) มีปุ่มใต้ข้อความ "ดูจุดบนแผนที่" (พาไปที่จุด/กรอบของจุดบนหน้าเว็บ) และ "แผนที่ไฟป่า"
- แต่ละจุด: เวลา (ตัวหนา) ดาวเทียม ตำบล/อำเภอ/จังหวัด สถานีฯ แล้วบรรทัดถัดไปเป็นลิงก์ **📍Google Maps** (นำทางไปที่พิกัด) และ **🔥แผนที่ไฟป่า** (เปิดรายละเอียดจุดบนหน้าเว็บ)
- ข้อความหนึ่งแสดงได้ราว 21–28 จุด (ปกติดาวเทียมรอบหนึ่งพบ 1–2 จุด สูงสุดปีงบ 2569 = 9) (พื้นที่ละไม่เกิน 20) เกินนั้นขึ้น "…และอีก N จุด" แต่ตัวเลขรวมนับครบ และปุ่ม "📍 ดู N จุด" ซูมให้เห็นทุกจุด
- ในกลุ่ม บอทไม่ตอบคำสั่งพิมพ์ (เช่น "สรุป") — ส่งอัตโนมัติอย่างเดียว · คำสั่งติดตามรายพื้นที่ใช้ใน**แชตส่วนตัว**กับบอท (ตอบช้า 5–10 นาที เพราะบอทไม่มีเซิร์ฟเวอร์รอรับ — ระบบอ่านคำสั่งทุกรอบ ~5 นาที)
- **ห้ามตั้ง webhook ให้บอทนี้** (เช่น setWebhook หรือเชื่อมกับบริการอื่น) — ระบบอ่านคำสั่งด้วย `getUpdates` ซึ่งใช้ไม่ได้เมื่อมี webhook (คำสั่ง `/ตาม` และ `chats` จะเสีย)

## 1. สร้างบอท

1. ในแอป Telegram ค้นหา **@BotFather** (มีเครื่องหมายถูกสีฟ้า) → กด **Start**
2. พิมพ์ `/newbot`
3. ตั้งชื่อที่แสดง เช่น `Hotspots สบอ.1`
4. ตั้ง username ภาษาอังกฤษ ต้องลงท้ายด้วย `bot` เช่น `hotspots_sbo1_bot`
5. BotFather ตอบ **token** หน้าตาแบบ `1234567890:AAH...` — **ห้ามส่งให้ใคร ห้ามวางในแชต**

## 2. เก็บ token ใน GitHub (ไม่ต้องใช้ Terminal)

repo `takiang71/fire-map-dpky` → **Settings → Secrets and variables → Actions → แท็บ Secrets → New repository secret**
- Name: `TG_TOKEN`
- Secret: วาง token จากข้อ 1

## 3. พาบอทเข้ากลุ่ม แล้วหารหัสกลุ่ม

1. เปิดกลุ่ม Telegram ที่จะรับแจ้งเตือน → แตะชื่อกลุ่ม → **Add members** → ค้นหา username ของบอท → เพิ่ม
   - ถ้าใช้ **channel** แทนกลุ่ม: เพิ่มบอทเป็น **Administrator** ที่มีสิทธิ์ Post messages
2. พิมพ์ในกลุ่ม: `/start@hotspots_sbo1_bot` (ใช้ username ของบอทคุณ)
3. GitHub → แท็บ **Actions** → เลือก **tg-test** (ซ้ายมือ) → **Run workflow** → เลือก `chats` → **Run workflow**
4. รอ ~1 นาที กดเข้ารายการที่รันเสร็จ → **send** → เปิดขั้น `Run node scripts/telegram_notify.js --chats` จะเห็นบรรทัดแบบ
   ```
   TG_CHAT_ID = -1001234567890   (supergroup) ชื่อกลุ่ม
   ```
   ถ้าไม่พบห้อง ให้พิมพ์ในกลุ่มอีกครั้งแล้วรันใหม่ (บอทเห็นข้อความย้อนหลังแค่ 24 ชม. · ระบบอ่านคำสั่งทุก ~5 นาที แต่จำรหัสกลุ่มที่เห็นไว้ 3 วัน `chats` จึงยังแสดง)
   - อีกวิธี: พิมพ์ `/id@ชื่อบอท` ในกลุ่ม แล้วรอ 5–10 นาที บอทจะตอบ `รหัสห้องนี้ (TG_CHAT_ID) = …` ในกลุ่ม

> repo เป็นสาธารณะ คนอื่นเห็น log นี้ได้ แต่รหัสกลุ่มอย่างเดียวส่งข้อความไม่ได้ (ต้องมี token ด้วย)

## 4. ตั้งรหัสกลุ่ม

**Settings → Secrets and variables → Actions → แท็บ Variables → New repository variable**
- `TG_CHAT_ID` = รหัสจากข้อ 3 (ใส่ในแท็บ Secrets ก็ได้ ระบบอ่านทั้งสองที่) (รวมเครื่องหมายลบ) · หลายห้องคั่นด้วยจุลภาค เช่น `-1001234567890,-1009876543210`
- (ไม่บังคับ) `TG_DAILY` = เวลาส่งสรุปประจำวัน เวลาไทย `HH:MM` (ไม่ตั้ง = 05:30 · `off` = ปิด)
- (ไม่บังคับ) `TG_BURN` = `off` ถ้าไม่ต้องการข้อความพื้นที่เผาไหม้
- (ไม่บังคับ) `TG_SUBS` = `off` ปิดการสมัครแจ้งเตือนรายพื้นที่ (ไม่อ่านคำสั่ง ไม่ส่งข้อความส่วนตัว — การสมัครที่มีอยู่ยังเก็บไว้)

## 5. ทดสอบ

Actions → **tg-test** → Run workflow → เลือก
- `test-push` = ข้อความแจ้งเตือนตัวอย่าง (จุดจริงล่าสุด 5 จุด ติดป้าย 🧪 ทดสอบ)
- `daily` = สรุปประจำวัน · `burn` = พื้นที่เผาไหม้รอบล่าสุด
- `preview` = แสดงข้อความทุกแบบใน log โดยไม่ส่ง

แจ้งเตือนจริงเริ่มเองในรอบถัดไปของ workflow `site` — **รอบแรกจะไม่ส่ง** (บันทึกจุดที่มีอยู่ว่าแจ้งแล้ว กันส่งจุดเก่าทั้งชุด) รอบต่อไปส่งเฉพาะจุดใหม่

## 6. (ไม่บังคับ) แจ้งผู้ดูแลเมื่อระบบเสียทาง Telegram

1. ในแอป Telegram เปิดแชตส่วนตัวกับบอท กด **Start**
2. พิมพ์ `/รหัส` (หรือ `/id`) แล้วรอ 5–10 นาที บอทจะตอบ `รหัสแชตนี้ = …`
   - `chats` ใน tg-test ไม่แสดงชื่อแชตส่วนตัวแล้ว (log ของ repo เป็นสาธารณะ และมีเจ้าหน้าที่หลายคนคุยกับบอทเพื่อสมัครแจ้งเตือนรายพื้นที่) แสดงแค่จำนวน
3. Variables → `TG_ADMIN_ID` = รหัสนั้น (ตัวเลขบวก)

รอบถัดไปบอทส่ง "✅ ตั้งค่าแจ้งเตือนผู้ดูแลเรียบร้อย" มาให้ จากนั้นจะแจ้งเรื่องเดียวกับ LINE (API/sync/ระบบต้นทาง/หน้าเว็บหยุด) และเพิ่ม:
- **Telegram ใช้งานไม่ได้** เกิน 1 ชม. (token ผิด / บอทถูกเอาออกจากกลุ่ม)
- **กลุ่มถูกอัปเกรดเป็น supergroup** — Telegram เปลี่ยนรหัสกลุ่มเมื่อกลุ่มใหญ่ขึ้นหรือเปิดบางการตั้งค่า ระบบส่งไปที่รหัสใหม่ให้เองทันที แต่ให้แก้ `TG_CHAT_ID` ตามข้อความ

ตั้งทั้ง `LINE_ADMIN_ID` และ `TG_ADMIN_ID` = ได้ทั้งสองทาง (LINE เสีย/โควตาหมด ก็ยังรู้ทาง Telegram)

## คำสั่งสำหรับเจ้าหน้าที่ (แจ้งเตือนรายพื้นที่)

ส่งต่อส่วนนี้ให้เจ้าหน้าที่ได้เลย:

1. ในแอป Telegram ค้นหาบอท **@Hotspot_dnp1_bot** (หรือแตะชื่อบอทในกลุ่ม) → **Start** / **ส่งข้อความ** — ต้องคุยใน**แชตส่วนตัว** ไม่ใช่ในกลุ่ม
2. พิมพ์คำสั่ง แล้วรอ **5–10 นาที** บอทจะตอบยืนยัน (บอทอ่านคำสั่งทุกรอบตรวจจุดความร้อน ~5 นาที ไม่ได้ตอบทันที)

| พิมพ์ | ผล |
|---|---|
| `/ตาม ทับลาน` | รับแจ้งเตือนจุดใหม่ใน อช.ทับลาน ถึงตัวเอง · หลายพื้นที่คั่นด้วยจุลภาคหรือเว้นวรรค เช่น `/ตาม ทับลาน, สถานีวังน้ำเขียว` หรือ `/ตาม tl ky` |
| `/เลิก ทับลาน` | เลิกติดตามพื้นที่นั้น (พื้นที่อื่นยังอยู่) |
| `/เลิกทั้งหมด` | หยุดรับข้อความส่วนตัวทั้งหมด |
| `/รายการ` | ดูว่าติดตามอะไรอยู่ |
| `/ช่วย` | วิธีใช้ + รายชื่อพื้นที่ทั้งหมด |

**ชื่อที่ใช้ได้** (พิมพ์แบบไหนก็ได้: `ทับลาน` `อช.ทับลาน` `อุทยานแห่งชาติทับลาน` `tl` — สะกดผิด 1 ตัวก็ยังรู้จัก):

| รหัส | พื้นที่อนุรักษ์ |
|---|---|
| `ky` | อช.เขาใหญ่ |
| `tl` | อช.ทับลาน |
| `ps` | อช.ปางสีดา |
| `tp` | อช.ตาพระยา |
| `dy` | ขสป.ดงใหญ่ (**สมัครได้** — ข้อความกลุ่มไม่รวมดงใหญ่) |
| `ks` | ขห.โคกสูง |
| `kc` | ขห.เขาฉกรรจ์ |
| `ทั้งหมด` | ทุกพื้นที่อนุรักษ์ข้างบน |

**สถานีควบคุมไฟป่า** — พิมพ์ "สถานี" นำหน้า: `/ตาม สถานีทับลาน` · `สถานีทับลาน ใต้` (หรือ `ทับลานใต้`) · `สถานีเขาใหญ่` · `สถานีเขาใหญ่ ใต้` · `วังน้ำเขียว` · `ตาพระยา-ปางสีดา` · `สถานีดงใหญ่` — สมัครสถานีฯ = ได้จุดในเขตรับผิดชอบของสถานีนั้น รวมจุดนอกพื้นที่อนุรักษ์ที่สถานีดูแล

**ข้อความที่ได้รับ:** รูปแบบเดียวกับข้อความกลุ่ม (เวลา ดาวเทียม ตำบล ลิงก์ Google Maps / แผนที่ไฟป่า ตารางสะสม) แต่มีเฉพาะจุดในพื้นที่ที่ติดตาม + บรรทัด "🔔 ตามที่คุณติดตาม: …" · กติกาเดียวกับกลุ่ม: จุดที่สแกนไม่เกิน 12 ชม. ไม่ส่งจุดเดิมซ้ำ · ติดตามทั้งพื้นที่และสถานีฯ ที่ซ้อนกัน จุดเดียวกันได้ครั้งเดียว · สรุปประจำวัน/พื้นที่เผาไหม้ยังอยู่ในกลุ่มเท่านั้น

**ความเป็นส่วนตัว:** ระบบเก็บแค่รหัสแชต (ตัวเลข) + พื้นที่ที่เลือก + วันที่สมัคร — ไม่เก็บชื่อหรือ username · ไฟล์ `tg_subs.json` อยู่ใน branch `state` ของ repo (ไม่ขึ้นหน้าเว็บ แต่ repo เป็นสาธารณะ — คนที่เข้าไปดู branch เห็นรหัสแชตได้ ส่งข้อความหาไม่ได้ถ้าไม่มี token) · **บล็อกบอท = ลบการสมัครอัตโนมัติ**

**พิมพ์คำสั่งในกลุ่ม** บอทตอบว่าใช้ได้เฉพาะแชตส่วนตัว (ไม่ตอบ `/start` ที่ใช้ตอนติดตั้งกลุ่ม)

**ลิงก์สมัครทันที** (ส่งให้เจ้าหน้าที่แตะ): `https://t.me/Hotspot_dnp1_bot?start=tl` = เปิดแชตแล้วกด Start ก็ติดตาม อช.ทับลาน · หลายพื้นที่ใช้ `-` คั่น เช่น `?start=tl-ky` (ใช้ได้เฉพาะรหัส ky tl ps tp dy ks kc)

## ตรวจปัญหา

- **ไม่มีแจ้งเตือน:** เปิด `…/fire-map-dpky/tg_notify.json`
  - ช่อง `tg`: `ok: 1` = token ใช้ได้และบอทอยู่ในห้อง (มีชื่อห้อง/จำนวนสมาชิก) · `ok: 0` + `why` = เหตุผล · `off` = ยังไม่ตั้ง secret/variable
  - ช่อง `log` (ใหม่สุดก่อน): ส่งแล้ว (`ok` = จำนวนห้องที่ส่งได้) หรือข้ามเพราะอะไร · รายการ `subs: 1` = แจ้งเตือนรายพื้นที่ (`cmd` คำสั่งที่อ่าน, `rep` คำตอบ, `dm` ข้อความส่วนตัวที่ส่ง, `blocked` ผู้ใช้บล็อกบอท→ลบ, `gu: 0` อ่านคำสั่งไม่ได้)
  - ช่อง `subs`: `n` จำนวนผู้สมัคร, `a` จำนวนต่อพื้นที่ (ไม่มีรหัสแชต), `gu.ok` = getUpdates ใช้ได้ไหม (`0` ต่อเนื่อง 1 ชม. → แจ้งผู้ดูแลเรื่อง `tgs`)
- **สมัครแล้วบอทไม่ตอบ:** รอ 10 นาที (ตอบรอบถัดไป) · ดู `subs.gu` — `409 Conflict … webhook` = มีคนตั้ง webhook ให้บอท ต้องลบ: เปิด `https://api.telegram.org/bot<TOKEN>/deleteWebhook` ในเบราว์เซอร์ (อย่าวาง token ในแชต/ที่สาธารณะ)
- **`403 Forbidden: bot was kicked`** = บอทถูกเอาออกจากกลุ่ม → เพิ่มกลับ
- **`400 Bad Request: chat not found`** = รหัสห้องผิด หรือบอทยังไม่ได้อยู่ในห้องนั้น
- **`401 Unauthorized`** = token ผิด หรือถูกเปลี่ยน (BotFather → /revoke) → แก้ secret `TG_TOKEN`
