## 1. หลักทั่วไป

- **ฐาน URL**: `https://takiang71.github.io/fire-map-dpky/` — ทุกไฟล์ในเอกสารนี้เป็นไฟล์คงที่ (static) บน GitHub Pages ไม่ต้องใช้ key ไม่ต้องล็อกอิน
- **CORS** เปิด (`Access-Control-Allow-Origin: *`) เรียกจากเบราว์เซอร์โดเมนอื่นได้ · `Cache-Control: max-age=600` (แคช 10 นาที — เติม `?t=<เวลา>` ถ้าต้องการค่าล่าสุดจริง)
- **ความถี่**: รอบ "site" ของ GitHub Actions ทุก ~5 นาที (cron-job.org สั่ง; ช้าได้ถึง 10–15 นาทีเมื่อ GitHub คิวยาว) · ไฟล์ที่มาจากรอบ "sync" อัปเดตวันละ 4 ครั้ง · ช่อง `generated`/`upd` บอกเวลาที่สร้างจริง
- **โปรดเกรงใจ**: ดึงไม่ถี่กว่า 5 นาทีต่อไฟล์ · ถ้าต้องการข้อมูลทั้งประเทศให้ดึงจากต้นทาง (ThaiREN / NASA FIRMS) ไม่ใช่จากระบบนี้ — ระบบนี้ตัดเฉพาะแนวเขตกลุ่มป่าแล้ว
- **ไฟล์ไม่มี = ใช้ค่ารอบก่อน**: ถ้ารอบไหนดึงต้นทางไม่สำเร็จ build จะไม่สร้างไฟล์นั้น (Pages ยังเสิร์ฟฉบับเดิม) → ตรวจ `generated` ก่อนใช้เสมอ
- **ไม่รับประกันความต่อเนื่องของสคีมา**: ช่องใหม่อาจเพิ่มได้ (โค้ดผู้ใช้ควรข้ามช่องที่ไม่รู้จัก) · การลบ/เปลี่ยนความหมายช่องจะบันทึกในเอกสารนี้
- **ไม่ใช่ข้อมูลทางการทุกตัว**: ตัวเลขตัวชี้วัดของกรมอุทยานฯ ที่เป็นทางการคือรายงานของกรมฯ · ดัชนีเสี่ยง (risk.json) เป็น**ดัชนีของระบบนี้ ไม่ใช่ค่าทางการ**

## 3. `live.json` — จุดความร้อน 48 ชม.

GeoJSON `FeatureCollection` รูปแบบเดียวกับ API Land Fire Alerts Thailand (ThaiREN) แต่ตัดเฉพาะจุดในแนวเขตกลุ่มป่า + ตัดจุดซ้ำ · ถ้า API ไทยล่ม ใช้ NASA FIRMS แทน (properties น้อยกว่า)

| ช่อง | ความหมาย |
|---|---|
| `meta.generated` | เวลาสร้าง (ISO UTC) |
| `meta.nation_total` | จำนวนจุดทั้งประเทศใน 48 ชม. (ก่อนตัดแนวเขต) |
| `meta.nation_last` | เวลาสแกนล่าสุดของทั้งประเทศ (เวลาไทย) |
| `meta.sys_update` | เวลาอัปเดตระบบต้นทาง |
| `meta.sats` | จำนวนจุดทั้งประเทศต่อดาวเทียม |
| `meta.fetch` | `{h: ชั่วโมงที่ดึงรอบนี้, full: เวลาดึงเต็ม 48 ชม. ครั้งล่าสุด}` |
| `features[].geometry.coordinates` | `[lon, lat]` WGS84 |
| `properties.full_date` | เวลาสแกน (เวลาไทย) |
| `properties.satellite_name` | `SNPP` / `NOAA20` / `NOAA21` |
| `properties.confidence` | `low` / `nominal` / `high` |
| `properties.province_name_th` `district_name_th` `subdistrict_name_th` (+ `_en`) | จังหวัด/อำเภอ/ตำบล ตามต้นทาง |
| `properties.protected_area_name_th` `reserved_forest_name` | พื้นที่อนุรักษ์/ป่าสงวน ตามต้นทาง |
| `properties.utm_easting` `utm_northing` `coordinate_zone` | UTM ตามต้นทาง |
| `properties.unique_id` | รหัสจุดของต้นทาง |
| `properties._ar` | **พื้นที่อนุรักษ์ตามแนวเขตของระบบนี้** (ใช้ช่องนี้ ไม่ใช่ของต้นทาง) |
| `properties._st` | สถานีควบคุมไฟป่าที่รับผิดชอบแปลง (`ไม่มี` = นอกแปลง) |

## 4. `summary.json` — ยอดสะสมปีงบ (ตัวชี้วัด)

ตัวเลขชุดเดียวกับการ์ด "สะสมปีงบ" ในหน้าเว็บ การ์ด LINE และสรุปประจำวัน Telegram (ตรวจทุกรอบด้วย `numcheck.json`) · นับเฉพาะ**ดาวเทียมตัวชี้วัด**ของแต่ละวัน · ปีงบก่อน = จุดกรมอุทยานฯ (Excel) ที่การจัดการเชื้อเพลิง "ไม่มี"

| ช่อง | ความหมาย |
|---|---|
| `generated` | เวลาสร้าง |
| `fy` | ปีงบปัจจุบัน (พ.ศ.) |
| `ind` | ชื่อดาวเทียมตัวชี้วัดวันนี้ (`NOAA-20`) |
| `adata_to` | วันสุดท้ายที่คลังจุดสะสมดึงครบ (หลังจากนั้นเติมจาก live.json) |
| `day` | วันที่เท่าไรของปีงบ (0 = 1 ต.ค.) |
| `total` | สะสมปีงบ**ทุกพื้นที่ รวมดงใหญ่** |
| `ar` / `st` | สะสมตามพื้นที่อนุรักษ์ / ตามสถานีฯ (รวมดงใหญ่) |
| `areas[คีย์]` | คีย์ = ชื่อพื้นที่อนุรักษ์ หรือ `นอกพื้นที่อนุรักษ์\|<สถานีฯ>` |
| `areas[].fy` | สะสมปีงบนี้ |
| `areas[].prv` | ปีงบก่อน**ช่วงเดียวกัน** (1 ต.ค. – วันเดียวกันของปีก่อน) |
| `areas[].pfull` | ปีงบก่อนทั้งปี |
| `areas[].m` / `pm` | รายเดือน ต.ค.–ก.ย. ปีนี้ / ปีก่อน (12 ช่อง) |
| `areas[].w` / `pw` | **รายสัปดาห์** ปีนี้ / ปีก่อนทั้งปี (53 ช่อง; ช่อง i = วันที่ 7i ถึง 7i+6 นับจาก 1 ต.ค.) — เพิ่ม 17 พ.ย. 69 |
| `areas[].sn` / `psn` | ตามสถานีฯ ปีนี้ / ปีก่อนช่วงเดียวกัน — เพิ่ม 17 พ.ย. 69 |
| `areas[].pv` `am` `tm` | สะสมปีนี้ตามจังหวัด / `อำเภอ\|จังหวัด` / `ตำบล\|อำเภอ\|จังหวัด` |

**ยอดไม่รวมดงใหญ่** (ค่าเริ่มต้นของหน้าเว็บ/LINE) = ผลรวม `areas[k].fy` ที่คีย์ `k` ไม่มีคำว่า `ดงใหญ่` · **% เทียบปีก่อนช่วงเดียวกัน** = `round((fy − prv) / prv × 100)` (prv = 0 ไม่คิด %)

## 5. `burn_summary.json` — พื้นที่เผาไหม้รอบล่าสุด

จากภาพ B4 (Sentinel-2, 20 ม.) ของระบบตามรอยเผา (สสน.) ที่ระบบดึงไว้ใน `data/burn/` · **ไม่รวมดงใหญ่แล้ว** · 1 พิกเซล = 0.25 ไร่

| ช่อง | ความหมาย |
|---|---|
| `p` `d0` `d1` | รหัสรอบ / วันเริ่ม / วันสิ้นสุด (`YYYYMMDD` ค.ศ.) |
| `rai` | ไร่ที่ไหม้ในรอบนี้ (ในแนวเขต) |
| `hs` | ไร่ที่มีจุดความร้อนภายใน `radius_m` เมตร ในช่วง d0−10 วัน ถึง d1 |
| `ar` `st` `pv` `am` `tm` | ไร่ตามพื้นที่อนุรักษ์ / สถานีฯ / จังหวัด / `อำเภอ\|จังหวัด` / `ตำบล\|อำเภอ\|จังหวัด` |
| `areas[ชื่อ]` | `{rai, hs, fy, m[12], st, pv, am, tm}` รายพื้นที่อนุรักษ์ (`fy` = สะสมปีงบ ไม่นับพิกเซลซ้ำ) |
| `m[12]` | ไร่สะสมรายเดือนของปีงบ |
| `fy` `fy_rai` `fy_periods` | ปีงบ / ไร่สะสมปีงบ / จำนวนรอบในปีงบ |
| `miss` | 1 = รอบนี้ต้นทางไม่มีภาพบางส่วน (เมฆ) ตัวเลขจริงอาจมากกว่า |

## 6. `watch.json` — พื้นที่เฝ้าระวังพิเศษ

GeoJSON จุด 48 ชม. ในพื้นที่เฝ้าระวัง (`properties._w` = รหัสพื้นที่) + `sum.areas[]`: `{id, n ชื่อเต็ม, s ชื่อย่อ, rai, bb กรอบ, fy, prv, pfull, m, pm, sat{ดาวเทียม: จำนวน}, tm{ตำบล|อำเภอ|จังหวัด: จำนวน}, h24, h48, last{t ms, sat, tm}, src{cur, prev: hist|api}}` · **นับทุกดาวเทียม** (ไม่ใช่ตัวชี้วัด) · อยู่นอกแนวเขตกลุ่มป่า จึงไม่รวมในยอดกลุ่มป่า

## 7. `risk.json` — ดัชนีเสี่ยงไฟป่า (ไม่ใช่ค่าทางการ)

โมเดล M2 (logistic: ความถี่ไฟในอดีตราย 10 วัน + FWI ของ TFDRS + มีจุดใน 3 วันก่อน) · วิธีคิด/ผลตรวจย้อนหลังในคู่มือหัวข้อ "พื้นที่เสี่ยงไฟป่า" · ไม่รวมดงใหญ่

| ช่อง | ความหมาย |
|---|---|
| `model` `note` `fys` | รุ่นโมเดล / หมายเหตุ / ช่วงปีงบที่ใช้หาความถี่ |
| `LVN` | ชื่อระดับ 1–5 (`ต่ำมาก` … `สูงมาก`) |
| `cols` | ชื่อคอลัมน์ของแถวใน `tm`/`st` |
