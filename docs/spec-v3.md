# Prompt: เว็บแอป "สถานการณ์ไฟป่ากลุ่มป่าดงพญาเย็น-เขาใหญ่ · แผนที่สามมิติ"

> ไฟล์นี้คือ Prompt ฉบับเต็ม (ฉบับแก้ไขโดยผู้ใช้ v3) เขียนจากภาพหน้าจอของเว็บต้นแบบ วางทั้งไฟล์ให้ AI ได้เลย
> AI จะทำ "เฟส 1" แล้วหยุดรอ พอตรวจแล้วพิมพ์ว่า "ไปเฟส 2" เพื่อทำเฟสถัดไป
> ส่วนที่ทำเครื่องหมาย (สมมติ) คือผู้เขียนสเปกเดา ปรับได้

---

## บทบาทและเป้าหมาย

คุณคือวิศวกร front-end ผู้เชี่ยวชาญแผนที่เว็บ (MapLibre GL JS) ช่วยสร้างเว็บแอป "สถานการณ์ไฟป่ากลุ่มป่าดงพญาเย็น-เขาใหญ่ (Dong Phayayen-Khao Yai Forest Complex) · แผนที่สามมิติ" ตามสเปกด้านล่าง ซึ่งเขียนจากภาพหน้าจอของเว็บต้นแบบ

- ทำตามรายละเอียดให้ใกล้เคียงที่สุด
- ส่วนที่สเปกไม่ได้ระบุ ให้เลือกแบบสมเหตุสมผล แล้วบอกสมมติฐานสั้นๆ ท้ายคำตอบ
- ส่วนที่ทำเครื่องหมาย (สมมติ) คือผู้เขียนสเปกเดา ให้ปรับได้

## 0. วิธีทำงาน (สำคัญ)

- สเปกยาว ให้ทำเป็นเฟสตามหัวข้อ 12 ตอนนี้ทำ "เฟส 1" เท่านั้น ส่งโค้ดที่รันได้จริง แล้วหยุดรอผมสั่งเฟสถัดไป ห้ามทำล่วงหน้า
- เฟสถัดไปให้ต่อยอดโค้ดเดิม ไม่เขียนใหม่ทั้งหมด และต้องไม่ทำให้ของเฟสก่อนพัง
- ค่าเริ่มต้นคือไฟล์ HTML ไฟล์เดียว (CSS/JS รวมในไฟล์) ถ้าเครื่องมือของคุณสร้างหลายไฟล์ได้ ให้แยกเป็น index.html, styles.css และโมดูล JS ตามเลเยอร์
- ข้อความบนหน้าเว็บทั้งหมดเป็นภาษาไทย ปีเป็น พ.ศ. เวลาเป็นเวลาไทย (UTC+7)
- เขียนโค้ดอ่านง่าย มีคอมเมนต์ภาษาไทยในจุดสำคัญ
- สคริปต์ภายนอกโหลดจาก cdnjs หรือ jsDelivr โดยระบุเวอร์ชันตายตัว (ห้าม @latest)
- ห้ามใช้ localStorage กับค่าที่จำเป็นต่อการทำงาน (ใช้เฉพาะจำค่าที่ผู้ใช้เลือก และครอบด้วย try/catch)
- ข้อมูลตัวอย่างก่อน: เวอร์ชันแรกใช้ mock data ที่สมจริง แยกฟังก์ชันดึงข้อมูลแต่ละเลเยอร์ให้ชัด เช่น `getHotspots()`, `getAirQuality()`, `getWindGrid()`, `getFireWeatherGrid()` เพื่อสลับเป็น API จริงทีหลังโดยแก้จุดเดียว
- ตัวเลขทุกตัวบนหน้าจอ (สถิติ จำนวนสถานี จำนวนจุด เปอร์เซ็นต์ ฯลฯ) ต้องคำนวณจากข้อมูลที่โหลด ห้าม hardcode ยกเว้นตัวเลขอ้างอิงคงที่ เช่น 77 จังหวัด 928 อำเภอ 7,425 ตำบล

## 1. ภาพรวมและเทคโนโลยี

- แผนที่เต็มจอ (100% viewport) ไม่มี header แยก ทุกอย่างลอยทับแผนที่
- MapLibre GL JS รองรับ terrain 3 มิติ (เปิด/ปิดได้) เปิดมาที่มุมมองครอบคลุมทั้งกลุ่มป่าดงพญาเย็น-เขาใหญ่ (Dong Phayayen-Khao Yai Forest Complex) ซึ่งประกอบไปด้วย อุทยานแห่งชาติเขาใหญ่ อุทยานแห่งชาติทับลาน อุทยานแห่งชาติปางสีดา อุทยานแห่งชาติตาพระยา และเขตรักษาพันธุ์สัตว์ป่าดงใหญ่ มุมมองจากด้านบน (ยังไม่เอียง)
- แผนที่ฐานโทนอ่อนแบบภูมิประเทศ มีเงาภูเขา (hillshade) พื้นที่ไทยแรเงาสีเขียวตามชนิดป่า เส้นขอบจังหวัดสีเทาเขียวบางๆ ประเทศเพื่อนบ้านจางลงกว่าไทย
- ซูมใกล้แล้วเห็นรายละเอียดเพิ่ม: ถนนสายหลักสีส้ม/เหลือง, แม่น้ำและอ่างเก็บน้ำสีฟ้า, ป่าเขียวเข้มพร้อมเงาภูมิประเทศ, เส้นแบ่งอำเภอ/ตำบล
- ระหว่างโหลดแสดง "กำลังโหลดแผนที่…" กลางจอ พื้นขาว
- meta: viewport `width=device-width, initial-scale=1, viewport-fit=cover`, theme-color `#ffffff`
- title: "สถานการณ์ไฟป่ากลุ่มป่าดงพญาเย็น-เขาใหญ่ (Dong Phayayen-Khao Yai Forest Complex) · แผนที่สามมิติ v1.0"

## 2. สไตล์ (design tokens)

- โทนสว่าง พื้นขาว/ครีมอ่อน สีหลักกรมท่า `#1B2A5E` สีเน้นไฟ `#D93A1F` (ประมาณจากภาพ ปรับได้)

- ปุ่ม/การ์ดพื้นขาว มุมมนใหญ่ เงาบางนุ่ม ไม่ใช้เส้นขอบหนา
- กำหนดสีเป็น CSS variables บน `:root` และรองรับ light/dark (prefers-color-scheme) แต่ค่าเริ่มต้นคือโทนสว่าง
- Mobile-first: ใช้ `env(safe-area-inset-*)` ที่ขอบจอ

## 3. แผงข้อมูลมุมซ้ายบน (ไม่มีกรอบการ์ด วางลอยบนแผนที่)

ฉากหลังเป็น gradient สีขาวโปร่งแสงจางๆ ให้ตัวหนังสืออ่านง่ายบนแผนที่ เรียงจากบนลงล่าง:

1. หัวข้อ "สถานการณ์ไฟป่ากลุ่มป่าดงพญาเย็น-เขาใหญ่ (Dong Phayayen-Khao Yai Forest Complex)" ตัวหนามาก ใหญ่ (~36-40px) สีกรมท่า
2. ป้ายเม็ดยา (pill) พื้นขาว ขอบบาง มีจุดเขียวเล็ก + "ล่าสุด 19:24 น." (เวลาอัปเดตข้อมูลล่าสุดจริง)
3. คำอธิบาย 2 บรรทัดสีเทาเข้ม: "ดูจุดความร้อนจากดาวเทียม ฝุ่น PM2.5 / AQI ทิศทางลม สภาพอากาศ และชนิดป่า ในกลุ่มป่าดงพญาเย็น-เขาใหญ่"
4. สถิติ 5 บรรทัด ตัวเลขหนาชิดขวาในคอลัมน์กว้างคงที่ ข้อความอยู่ถัดไป:
   - เลขสีแดง "87" จุดความร้อน 24 ชม. ล่าสุด (= จุดภายใน 6 ชม. + จุด 6-24 ชม. ไม่รวมจุดเก่ากว่า 24 ชม.)
   - "24" พื้นที่ที่พบจุดความร้อน
   - "13" จุดในจังหวัดนครราชสีมา พบมากที่สุด (ชื่อจังหวัดคำนวณจากข้อมูล)
   - "8" จุดในอำเภอ พบมากที่สุด (ชื่ออำเภอคำนวณจากข้อมูล)
   - "5" จุดในตำบล พบมากที่สุด (ชื่อตำบลคำนวณจากข้อมูล)
5. บรรทัดเล็กสีเทาจาง: "อัปเดต 19:24 น. · NOAA-20, NOAA-21 · ย้อนหลัง 2 วัน"
6. ปุ่มพื้นขาว มุมมน เงาบาง เรียงเป็นแถวและตัดบรรทัดอัตโนมัติ:
   - "ซ่อนรายการ" (ไอคอน X) กดแล้วซ่อนการ์ดรายชื่อจังหวัด และเปลี่ยนเป็น "แสดงรายการ"
   - "เรียนรู้ชนิดป่า" เปิด modal อธิบายชนิดป่า (หัวข้อ 11)
   - "วิเคราะห์สถิติย้อนหลัง" เปิด modal สถิติ (หัวข้อ 11)
   - "ย้อนดูการลามของไฟ" เปิดแถบเวลาย้อนหลัง (หัวข้อ 11)
   - "คู่มือการใช้งาน" (ไอคอนหนังสือ) เปิด modal คู่มือ (หัวข้อ 11)
7. การ์ดรายชื่อ (พื้นขาว มุมมนใหญ่ เงาเบา กว้างประมาณ 335px สูงจำกัด เลื่อนได้ scrollbar บาง):
   - ช่องค้นหา "ค้นหาจังหวัด" + ไอคอนแว่นขยาย กรองรายการแบบเรียลไทม์ กดปุ่ม "/" เพื่อโฟกัสช่องค้นหา
   - แท็บ "จังหวัด 24" (ตัวเลขสีเทาจาง นับจากข้อมูลจริง) ขีดเส้นใต้สีกรมท่า มีแท็บเดียว ไม่มีแท็บ "เพื่อนบ้าน" เพราะข้อมูลตัวอย่างไม่มีจุดนอกประเทศ
   - ข้อความแนะนำเล็กสีเทา: "นับเฉพาะ 24 ชั่วโมงล่าสุด · เลือกเพื่อซูมไปยังพื้นที่ · กด / เพื่อค้นหา" (สมมติ)
   - แถวรายการ: แท่งสีส้มแดงสั้น (ความยาวตามสัดส่วนจำนวนจุด) + ชื่อจังหวัด + "13 จุด" ชิดขวา เรียงจากมากไปน้อย กดแถวแล้ว flyTo ไปจังหวัดนั้น
8. บนมือถือ: แผงนี้ย่อเป็น bottom sheet ลากขึ้นลงได้

## 4. เครื่องหมายบนแผนที่

- **จุดความร้อน:** ไอคอนเปลวไฟ SVG มีวงกลมเรืองแสง (glow) รองอยู่ แยก 3 กลุ่มตามอายุ
  - แดง = ภายใน 6 ชม.
  - ส้ม = 6-24 ชม.
  - น้ำตาล = เก่ากว่า 24 ชม. (จางและโปร่งแสงกว่า)
  - โหลดข้อมูลย้อนหลัง 2 วัน ซูมออกให้รวมกลุ่ม (cluster) ได้
- **สถานีวัดฝุ่น PM2.5/AQI:** ซูมไกล = สี่เหลี่ยมมุมมนเล็ก ขอบขาว / ซูมใกล้ = กล่องมุมมนมีตัวเลข AQI ข้างใน สีตามเกณฑ์ AQI สากลในหัวข้อ 6.3 เทา = ไม่มีข้อมูลหรือไม่อัปเดต
- **เส้นลม:** เส้นสั้นบางๆ โปร่งแสงกระจายทั่วแผนที่ ชี้ตามทิศลม (เฟสแรกใช้เส้นคงที่ ต่อมาทำอนิเมชันไหล)
- **คลิกจุดความร้อน:** flyTo ซูมเข้าให้เห็นถนนและแหล่งน้ำรอบจุด (สเกลบาร์ราว 30 กม.) มีวงแหวนเน้นที่จุด แล้วเปิดแผงรายละเอียด (หัวข้อ 7)
- **คลิกตำแหน่งอื่นบนแผนที่:** popup สภาพอากาศ พิกัด ปุ่มเส้นทางนำทาง และชื่อตำบล/อำเภอ

## 5. ปุ่มควบคุมและส่วนประกอบรอบแผนที่

- **มุมขวาล่าง** ปุ่มสี่เหลี่ยมมุมมนสีขาว เงาบาง เรียงแนวนอน ใช้ไอคอนล้วน ไม่มีป้ายข้อความ ตามลำดับ:
  - ตำแหน่งของฉัน
  - สลับการแสดงสถานีวัดฝุ่น (ไอคอนวงกลมจุด)
  - ชั้นข้อมูล (ไอคอนชั้นซ้อน เปิดแผงหัวข้อ 6)
  - ซูมเข้า/ออก (ซ้อนแนวตั้ง)
  - โหมด 3 มิติ (ไอคอนภูเขา)
  - เข็มทิศ (รีเซ็ตทิศเหนือ)
  - กลับมุมมองเริ่มต้น (ไอคอนบ้าน)
- ปุ่มที่เปิดอยู่ (ชั้นข้อมูล, 3 มิติ) พื้นสีกรมท่า ไอคอนขาว
- **โหมด 3 มิติ:** เปิด terrain + เอียงกล้อง (pitch ~60°) จุดความร้อนเปลี่ยนเป็นแท่ง 3 มิติ ความสูง = ความแรงไฟ (FRP) ซิงก์สถานะกับสวิตช์ "มุมมอง 3 มิติ" ในแผงชั้นข้อมูล
- **กลางล่าง** ข้อความแนะนำสีเทาตัวเล็ก: "คลิกจุดความร้อนหรือตำแหน่งใดบนแผนที่ เพื่อดูสภาพอากาศ พิกัด และเส้นทางนำทาง"
- **มุมซ้ายล่าง** แถบสเกลระยะ (เช่น 20 km / 30 km / 300 km)
- **ล่างสุด** แถบ attribution บรรทัดเดียว ตัวเล็กจาง:
  "จุดความร้อน NASA FIRMS · อากาศ Open-Meteo, MET Norway · ฝุ่น PM2.5 กรมควบคุมมลพิษ (Air4Thai), Copernicus CAMS · ชนิดป่า © กรมป่าไม้ 2561 · แนวเขต © กรมแผนที่ทหาร (OCHA HDX) · แผนที่ © OpenStreetMap, OpenMapTiles, OpenFreeMap, Natural Earth"
- **แผงขวาบน** (ชั้นข้อมูล / รายละเอียดจุดความร้อน) ใช้ตำแหน่งเดียวกัน เปิดอันหนึ่งให้ปิดอีกอัน กว้างประมาณ 330-360px พื้นขาว มุมมนใหญ่ เงานุ่ม สูงไม่ทับปุ่มขวาล่าง เลื่อนภายในแผงได้ scrollbar บาง บนมือถือให้เป็น bottom sheet

## 6. แผงชั้นข้อมูล (เปิดจากปุ่มชั้นซ้อน)

รูปแบบแถว: ไอคอนซ้าย + ชื่อชั้น + สวิตช์ชิดขวา + คำอธิบายตัวเล็กสีเทาใต้แถว
สวิตช์: ปิด = เทาอ่อนปุ่มกลมขาว / เปิด = พื้นกรมท่า ค่าเริ่มต้นทุกสวิตช์ด้านล่าง = เปิด ยกเว้นที่ระบุว่าปิด ตัวเลขในคำอธิบายนับจากข้อมูลจริง

แถบหัว: "ชั้นข้อมูล" ตัวหนาชิดซ้าย / ลิงก์ขีดเส้นใต้สีกรมท่า "ตั้งที่เลือกเป็นค่าเริ่มต้น" (บันทึกค่าที่เลือกทั้งหมดลง localStorage ครอบ try/catch และโหลดตอนเปิดเว็บ) / ปุ่ม X

### 6.1 หมวด "แผนที่ฐาน"

- ปุ่มเลือกแบบแถบต่อกัน 5 ช่อง: ธรรมชาติ (ค่าเริ่มต้น) / เรียบ / ดาวเทียม / ละเอียด / ถนน ช่องที่เลือกพื้นฟ้าม่วงอ่อน ตัวหนาสีกรมท่า ช่องอื่นพื้นขาวขอบเทาบาง
- แต่ละแบบสลับ style ของ MapLibre โดยคงเลเยอร์ข้อมูล (จุดไฟ ฝุ่น ลม ฯลฯ) ไว้ไม่หาย:
  - ธรรมชาติ = hillshade + สีพื้นที่ป่าแบบภูมิประเทศ
  - เรียบ = โทนสว่างเรียบ ลดรายละเอียด (เช่น OpenFreeMap Positron)
  - ดาวเทียม = ภาพถ่ายดาวเทียม
  - ละเอียด = ถนน อาคาร ชื่อสถานที่ครบ (เช่น OpenFreeMap Liberty)
  - ถนน = เน้นเครือข่ายถนน (เช่น OpenFreeMap Bright)
- สวิตช์ "มุมมอง 3 มิติ" (ไอคอนภูเขา) ค่าเริ่มต้นปิด

### 6.2 หมวด "ไฟและควัน" (เรียงตามลำดับ)

#### (1) จุดความร้อน

- ไอคอนเปลวไฟ 3 ดอก (แดง ส้ม น้ำตาล) + สวิตช์
- แถวย่อยเยื้องเข้า ไอคอนเปลวตามสี + คำอธิบาย + จำนวนชิดขวา:
  - แดง "ภายใน 6 ชม."
  - ส้ม "6-24 ชม."
  - น้ำตาล "เก่ากว่า 24 ชม."
- หมายเหตุ: "ดาวเทียม VIIRS ความละเอียด 375 ม. จาก NASA FIRMS อัปเดตทุก 15 นาที · มุมมอง 3 มิติ ความสูงแท่ง = ความแรงไฟ (FRP)"
- ลิงก์ไอคอนรีเฟรช "ดึงข้อมูลใหม่" กดแล้วโหลดใหม่ และรีเฟรชอัตโนมัติทุก 15 นาที

#### (2) ทิศทางลมปัจจุบัน

- ไอคอนเส้นลมสั้น + สวิตช์ แถบสเกลเส้นประไล่บางจาง→หนาเข้ม ป้าย "ลมเบา" ซ้าย "ลมแรง" ขวา
- คำอธิบาย: "เส้นไหลไปทางที่ลมพัดไป เส้นยาวและไหลเร็วขึ้น = ลมแรง · Open-Meteo ตามบริเวณที่มองเห็น ปรับทุก 15 นาที"
- ข้อมูล: ลมที่ระดับ 10 ม. เป็นตารางจุดภายในกรอบแผนที่ที่มองเห็น (เลื่อน/ซูมแล้วโหลดใหม่) รีเฟรชทุก 15 นาที

#### (3) ฝุ่น PM2.5 / AQI

รายละเอียดในหัวข้อ 6.3

#### (4) อากาศแห้ง เสี่ยงเกิดไฟป่า

รายละเอียดในหัวข้อ 6.4

#### (5) จุดความร้อนย้อนหลัง

- ไอคอนแถบไล่เหลือง→ส้ม→แดง + ป้ายเล็ก "ยังไม่นำเข้า" (เปลี่ยนเป็นจำนวนจุดเมื่อนำเข้าแล้ว) + สวิตช์
- แสดงเป็น heatmap จากข้อมูลที่ผู้ใช้นำเข้า (หัวข้อ 6.8)

### 6.3 ฝุ่น PM2.5 / AQI

- ไอคอนสี่เหลี่ยมมุมมนเล็ก 3 ช่องเรียงแนวนอน (เขียว เหลือง ส้ม) + "ฝุ่น PM2.5 / AQI" + เวลาข้อมูลตัวเล็กสีเทา "14:00 น." + สวิตช์
- ปุ่มแถบต่อกัน 2 ช่อง: "AQI (ดัชนีสากล)" (ค่าเริ่มต้น) / "PM2.5 (µg/m³)" สลับตัวเลขในป้ายสถานี
- บรรทัดเล็กสีเทา: "ช่วงเวลา: ค่าปัจจุบัน หรือพยากรณ์ฝุ่นล่วงหน้า (CAMS)"
- แถวชิปวัน เลื่อนแนวนอนได้ ชิปสี่เหลี่ยมมุมมนกว้างราว 60px: "ตอนนี้" (บรรทัดล่าง "สด" สีแดง) / "พรุ่งนี้" / ชื่อวันย่ออีก 3 วัน (พฤ. ศ. ส. คำนวณจากวันที่จริง)
  - ชิปวันพยากรณ์มีขีดสีสั้นคั่นกลางและเปอร์เซ็นต์ตัวหนาด้านล่าง (= สัดส่วนพื้นที่ไทยที่ AQI เกิน 100 ในวันนั้น)
  - ชิปที่เลือกขอบแดงส้ม พื้นอมครีม
  - "ตอนนี้" = ข้อมูลสถานีจริง / วันอื่น = พยากรณ์ CAMS (Open-Meteo Air Quality)
- Legend 6 แถว (สี่เหลี่ยมสี | ช่วง AQI ตัวหนา | ชื่อระดับ | ช่วง PM2.5 ตัวเล็กสีเทา) หัว: "AQI สากล (US EPA) · PM2.5 เฉลี่ย 24 ชม. µg/m³"
  - เขียว `#00E400` · 0-50 · ดี · PM2.5 0-9
  - เหลือง `#FFFF00` · 51-100 · ปานกลาง · PM2.5 9.1-35.4
  - ส้ม `#FF7E00` · 101-150 · เริ่มมีผลต่อกลุ่มเสี่ยง · PM2.5 35.5-55.4
  - แดง `#FF0000` · 151-200 · มีผลต่อสุขภาพ · PM2.5 55.5-125.4
  - ม่วง `#8F3F97` · 201-300 · มีผลต่อสุขภาพมาก · PM2.5 125.5-225.4
  - เลือดหมู `#7E0023` · 301+ · อันตราย · PM2.5 225.5 ขึ้นไป
- AQI คำนวณด้วย interpolation เชิงเส้นตามช่วง PM2.5 ข้างต้น (เช่น PM2.5 9.3 → AQI 51)
- หมายเหตุ: "สี่เหลี่ยม = สถานีตรวจวัดกรมควบคุมมลพิษ 162 สถานี ซูมระดับจังหวัดเห็นค่า AQI (สีเทา = ไม่มีข้อมูล/ไม่อัปเดต) · พื้นผิวและเส้นชั้นค่า = แบบจำลอง CAMS ครอบคลุมเพื่อนบ้าน เป็นค่าประมาณ · ใช้ร่วมกับทิศทางลมดูควันข้ามแดน"

### 6.4 อากาศแห้ง เสี่ยงเกิดไฟป่า

- ชื่อชั้น (ขึ้น 2 บรรทัดได้) + ข้อความเล็ก "0% เสี่ยงสูง" (= สัดส่วนพื้นที่ประเทศที่ FWI ≥ 75 ในวันที่เลือก) + สวิตช์
- ปุ่มแถบต่อกัน 3 ช่อง: "ดัชนีไฟป่า FWI" (ค่าเริ่มต้น) / "ความชื้นต่ำสุด" / "ความแห้ง VPD" เปลี่ยนตัวแปรที่ระบายสีบนแผนที่และ legend
- ชิปวัน 7 ช่อง เลื่อนแนวนอนได้: "วันนี้" + ชื่อวันย่อ 6 วันถัดไป แต่ละชิปมีขีดสีส้มสั้นและเปอร์เซ็นต์พื้นที่เสี่ยงสูง ชิปที่เลือกขอบแดง
- Legend "ดัชนีอันตรายไฟป่า (FWI / CBI)" 5 ระดับ:
  - ≥ 0 ต่ำ (เขียวเทาอ่อน)
  - ≥ 50 ปานกลาง (เหลืองทราย)
  - ≥ 75 สูง (ส้มอ่อน)
  - ≥ 90 สูงมาก (แดงอิฐ)
  - ≥ 97.5 วิกฤต (เลือดหมู)
- สถิติ 3 แถว จุดสีนำหน้า ค่าชิดขวา (คำนวณจากข้อมูลวันที่เลือก):
  - จุดส้ม "พื้นที่เสี่ยงสูงขึ้นไป (FWI ≥ 75)" เป็น %
  - จุดแดง "เสี่ยงสูงมาก–วิกฤต (FWI ≥ 90)" เป็น %
  - จุดเลือดหมู "ความชื้นต่ำสุดในประเทศ" เป็น %
- หมายเหตุ: "รวมผลอุณหภูมิสูงสุด ความชื้นต่ำสุด ลม และฝน (Chandler Burning Index) · ≥ 75 = เชื้อเพลิงแห้ง ติดไฟง่าย · พยากรณ์รายวัน Open-Meteo ตาราง ~55 กม. ปรับทุก 6 ชม. · ชี้เมาส์บนแผนที่เพื่อดูค่า · ข้อมูล 10:38 น." (เวลาที่คำนวณล่าสุดจริง)
- ลิงก์ไอคอนรีเฟรช "คำนวณใหม่"
- บนแผนที่เป็นพื้นผิวสีตาม legend ครอบคลุมไทย ชี้เมาส์แล้วแสดงค่าที่ตำแหน่งนั้น

### 6.5 หมวด "แนวเขต"

- จังหวัด: ไอคอนเส้นทึบ · "77 จังหวัด แนวเขตทางการ กรมแผนที่ทหาร ใช้แยกนับจุดความร้อนรายจังหวัด"
- อำเภอ: ไอคอนเส้นประ · "928 อำเภอ แนวเขตทางการ แสดงเมื่อซูมระดับจังหวัด"
- ตำบล: ไอคอนเส้นจุด · "ครบ 7,425 ตำบล แสดงเมื่อซูมระดับอำเภอ · คลิกบนแผนที่เพื่อดูชื่อตำบลและอำเภอ"
- ป่าอนุรักษ์ / ป่าสงวน: ไอคอนสี่เหลี่ยมมุมมนเขียวอ่อนขอบเขียว · "อุทยาน เขตรักษาพันธุ์ จาก OpenStreetMap แสดงได้ทุกระดับซูม · นำเข้าข้อมูลทางการแทนได้"
- ข้อมูลระดับตำบลมีขนาดใหญ่มาก เฟสแรกใช้ข้อมูลตัวอย่าง/ย่อ แล้วค่อยเปลี่ยนเป็น vector tiles (PMTiles) หรือโหลดตามอำเภอ

### 6.6 หมวด "น้ำและเส้นทาง"

- แม่น้ำ ลำห้วย อ่างเก็บน้ำ: เส้นสีฟ้า · "แม่น้ำและอ่างเก็บน้ำแสดงทุกระดับซูม ลำห้วยเล็กแสดงเมื่อซูมใกล้ · ไม่กินโควตา"
- ถนน ทางรถ ทางเดิน: เส้นสีส้ม · "ทางหลวงแสดงทุกระดับซูม ทางรถในป่า (เส้นประน้ำตาล) ทางเดิน และถนนเล็กแสดงเมื่อซูมใกล้ · ไม่กินโควตา"
- สองแถวนี้เปิด/ปิดเลเยอร์น้ำและถนนของแผนที่ฐานด้วย `setLayoutProperty('visibility')`

### 6.7 หมวด "ข้อมูลของสถานี"

- เส้นทางลาดตระเวน: เส้นสีม่วง · ป้ายเล็ก "–" (แสดงจำนวนเมื่อมีข้อมูล)
- ความหนาแน่นเชื้อเพลิง: ไอคอนไล่เขียว→เหลือง→แดง
- ชนิดป่า: ไอคอนไล่เขียว · ป้ายเล็ก "กรมป่าไม้ 2561" ใต้แถวนี้เยื้องเข้าไปมี:
  - หัวข้อ "ความเสี่ยงไฟตามชนิดป่า" + legend 6 แถว (สี่เหลี่ยมสี | ระดับตัวหนา | ชนิดป่าสีเทา) สีไล่จากเขียวอ่อน (เสี่ยงมาก) ไปเขียวเข้ม (เสี่ยงน้อย) และเทา:
    - สูงมาก — ป่าเต็งรัง · ป่าเบญจพรรณ
    - สูง — ป่าสนเขา · ป่าไผ่ · ทุ่งหญ้า / ป่าทุ่ง
    - ปานกลาง — สวนป่า / ป่าปลูก · ป่าดิบแล้ง · ป่าดิบเขา · ป่าพรุ
    - ต่ำ — ป่าดิบชื้น · ป่าชายหาด
    - ต่ำมาก — ป่าชายเลน
    - ไม่ทราบ (เทา) — ป่าที่ฟื้นฟูตามธรรมชาติ · สังคมพืชสนามหิน (ยังไม่มีข้อมูลลักษณะไฟ)
  - หมายเหตุ: "แผนที่ชนิดป่า กรมป่าไม้ ปี 2561 (Sentinel-2 10 ม.) ซูมออกเห็นภาพรวม ซูมเข้าระดับจังหวัดเห็นทุกแปลง · คลิกพื้นที่ป่าเพื่อดูชนิดไฟ ช่วงเกิดไฟ และเชื้อเพลิงหลัก"
  - ลิงก์ขีดเส้นใต้สีกรมท่า "เรียนรู้ชนิดป่าแต่ละโซน (6 ภาค · 12 ชนิดป่า)" เปิด modal เดียวกับปุ่ม "เรียนรู้ชนิดป่า"
  - คลิกพื้นที่ป่าบนแผนที่ → popup ชนิดป่า ชนิดไฟ ช่วงเกิดไฟ เชื้อเพลิงหลัก
- การจัดการเชื้อเพลิง: เส้นประสีส้ม · ป้ายเล็ก "–"
- ตำแหน่งชุดปฏิบัติการ: จุดกลมสีม่วง · ป้ายเล็ก "ไม่ได้เชื่อม"

### 6.8 ปุ่ม "นำเข้าข้อมูล"

- ปุ่มเต็มความกว้าง พื้นขาว ขอบกรมท่า ตัวหนา ตรึงอยู่ล่างสุดของแผง (ไม่เลื่อนไปกับเนื้อหา)
- กดแล้วเปิด modal: เลือกไฟล์ (GeoJSON, CSV ที่มีคอลัมน์ lat/lon, KML) และเลือกว่านำเข้าเป็นชั้นไหน (จุดความร้อนย้อนหลัง / เส้นทางลาดตระเวน / ความหนาแน่นเชื้อเพลิง / การจัดการเชื้อเพลิง / ตำแหน่งชุดปฏิบัติการ / ป่าอนุรักษ์ทางการ)
- ประมวลผลในเบราว์เซอร์ทั้งหมด ไม่อัปโหลดไปไหน เมื่อสำเร็จป้ายสถานะของชั้นนั้นเปลี่ยนเป็นจำนวนรายการ และแผนที่ซูมไปที่ข้อมูล

## 7. แผงรายละเอียดจุดความร้อน (เปิดเมื่อคลิกจุดไฟ)

ลอยมุมขวาบน กว้างราว 360px พื้นขาว มุมมนใหญ่ เงานุ่ม เลื่อนภายในได้ ปิดด้วยปุ่ม X หรือคลิกพื้นที่ว่างบนแผนที่

### 7.1 ส่วนหัวของแผง (เรียงจากบนลงล่าง)

1. แถบหัว: ข้อความเล็กสีเทา "จุดความร้อน · NOAA-21" (ชื่อดาวเทียมจริง) ชิดซ้าย ปุ่มไอคอนชิดขวา 3 ปุ่ม: คัดลอกพิกัด/ลิงก์, แชร์/เส้นทางนำทาง, ปิด
2. ชื่อตำแหน่งตัวหนาใหญ่สีกรมท่า ขึ้นบรรทัดใหม่ได้ "ตำบล{X} อำเภอ{Y} จังหวัด{Z}" (หาจากพิกัดด้วย point-in-polygon กับขอบเขตตำบล ใช้ Turf.js)
3. แถวตัวเลขเด่น
   - ซ้าย: ไอคอนเปลวไฟ + "24.1" ใหญ่ + "ชั่วโมงที่แล้ว" (อายุของจุด)
   - ขวา: "ความแรงไฟ" + "7.7" ใหญ่ + "MW" (FRP)
4. เส้นคั่นบาง แล้วตารางข้อมูล 2 คอลัมน์ ป้ายเล็กสีเทา ค่าสีเข้ม:
   - เวลาที่ตรวจพบ: "20 ต.ค. 2569 13:57 น." / ความเชื่อมั่น: ต่ำ / ปกติ / สูง
   - พิกัด: "15.14207, 101.26955" / UTM: "UTM 47N · E 743,887 N 1,675,302" (เลือกโซน 47N/48N จากลองจิจูด ใช้ proj4js)
   - ความสูง: "127 ม. รทก." (Open-Meteo Elevation API)

### 7.2 การ์ดคาดการณ์การลุกลามและผลกระทบ

การ์ดพื้นสีพีชอ่อน ขอบส้มบาง มุมมน
หัวตัวหนา "คาดการณ์การลุกลามและผลกระทบ" ชิดซ้าย / ลิงก์ขีดเส้นใต้ "ซูมดูวงคาดการณ์" ชิดขวา (ซูมแผนที่ไปดูวงรี)
ข้อความอ้างอิงเล็กสีเทา: "จำลองด้วยสมการฟิสิกส์ไฟป่า Rothermel (1972) · วงรี Anderson (1983) · ความรุนแรง Byram (1959) · กลุ่มควัน Gaussian Plume"
มีการ์ดขาวมุมมนซ้อนข้างใน ประกอบด้วย:

#### (A) ตัวควบคุม

1. "ระยะเวลาคาดการณ์" + ปุ่มแถบต่อกัน 5 ช่อง: 1 ชม. | 3 ชม. | 6 ชม. | 12 ชม. | 24 ชม. (ค่าเริ่มต้น 6 ชม. เปลี่ยนแล้วคำนวณและวาดใหม่ทันที)
2. "เชื้อเพลิงป่าไม้" + "(ประเมินตามภูมิภาค/ความสูง)" ใต้เป็น dropdown เต็มความกว้าง รูปแบบ "ป่าเบญจพรรณ (0.85 ตัน/ไร่)" เลือกอัตโนมัติจากชนิดป่าและภาคของจุด ผู้ใช้เปลี่ยนเองได้ ค่า 0.85 ของเบญจพรรณมาจากต้นแบบ ชนิดป่าอื่นใช้ค่าประมาณสมเหตุสมผล เก็บในตัวแปรคงที่ตัวเดียวที่แก้ง่าย

   - ส่วนเต็มสีเหลืองอำพัน = EMC ÷ ความชื้นจุดไฟดับเอง (11.6/24 ≈ 48%) สีแถบตามระดับ (แห้งมาก แดง / ปานกลาง เหลืองอำพัน / ชื้น เขียว)
   - ใต้แถบข้อความเล็กสีเทา "เชื้อเพลิงแห้งปานกลาง ไฟลุกลามต่อเนื่องตามทิศลม · รูปทรงวงรีไฟป่า L/B = 1.2 : 1" (คำว่าแห้งปานกลางเปลี่ยนตามค่า EMC)
7. การ์ดระดับความรุนแรง พื้นครีมอ่อน แถบซ้ายหนาสีเหลืองอำพัน:
   - หัวตัวหนา "ระดับที่ 2 · ไฟความรุนแรงปานกลาง (ต้องทำแนวกันไฟดักด้านข้าง)"
   - เนื้อความ "ความร้อนที่หัวไฟสูงเกินกว่าจะเข้าตบไฟตรง ๆ (เปลวสูง ~1.6 ม.) ให้เข้าตีขนาบจากท้ายไฟและด้านข้าง (Flank Attack) พร้อมทำแนวกันไฟดักล่วงหน้า"
   - กล่องขาวมุมมนด้านใน "กำลังพลที่แนะนำ: อย่างน้อย 12 ชุดปฏิบัติการ (สำหรับสกัดแนวขอบไฟ 6.4 กม.)" ("อย่างน้อย 12 ชุดปฏิบัติการ" ตัวหนา)
   - ระดับตามความสูงเปลวไฟ (อิงตาราง Hauling): < 1.2 ม. = ระดับ 1 (เข้าตบไฟตรงๆ ได้) / 1.2-2.4 = ระดับ 2 / 2.4-3.4 = ระดับ 3 (ต้องใช้เครื่องจักร) / > 3.4 = ระดับ 4 (เสี่ยงไฟเรือนยอด) ข้อความและสีแถบซ้ายเปลี่ยนตามระดับ (ระดับ 1,3,4 สมมติ)
   - จำนวนชุด = ความยาวขอบไฟ ÷ 0.5 กม. ปัดลงเป็นจำนวนเต็ม อย่างน้อย 1 (6.4 กม. → 12 ชุด)
8. หัวตัวหนา "ประเมินผลกระทบสิ่งแวดล้อมและพื้นที่ใต้ลม" มีเส้นคั่นด้านบน แล้วตาราง ป้ายซ้ายสีเทา / ค่าขวาสีเข้ม:
   - ทิศไฟและควันพัดไป: "ทิศตะวันตก (253°)"
   - มวลชีวมวลที่ถูกเผา: "1,373.0 ตัน (เชื้อเพลิง 0.85 ตัน/ไร่)"
   - ผลกระทบฝุ่นใต้ลม 5 กม.: "PM2.5 เพิ่มขึ้นราว +950 µg/m³ ในแกนกรวยควัน"
   - ความเสียหายของต้นไม้: "อัตราตายของไม้หนุ่ม/ไม้พื้นล่าง 5-12% (ถ้าอากาศแห้งทำให้เปลวไฟพุ่งสูง 5-6 ม. ลวกเรือนยอดไม้สัก/ประดู่)"
   - เวลาฟื้นตัวของป่า: "2-4 ปี"
   - สองแถวสุดท้ายเป็นตารางค้นหาตามระดับความรุนแรง (1-4) x ชนิดป่า ใส่ค่าประมาณสมเหตุสมผล (สมมติ) แก้ง่าย
   - ท้ายตารางมีหมายเหตุตามชนิดป่า เช่น "ไฟในดงไผ่แห้งมีความร้อนสูงและเกิดเสียงลำไผ่ระเบิด อาจเปิดช่องว่างเรือนยอดและทำให้ไฟรุกพื้นที่ไม้ใหญ่"
9. การ์ดพื้นสีพีชอ่อน หัว "พื้นที่ใต้ลมที่เสี่ยงได้รับผลกระทบ (ไฟลาม / กลุ่มควัน):" ตามด้วย 3 แถว ป้ายสีเทา + ชื่อพื้นที่ตัวหนา:
   - "หน้าไฟ (1.7 กม.):" ตำบล อำเภอ จังหวัด
   - "ใต้ลม 7 กม.:" ตำบล อำเภอ จังหวัด
   - "ปลายกรวยควัน (~24 กม.):" ตำบล อำเภอ จังหวัด
   - คำนวณโดยเดินจากจุดไฟตามทิศลมไปตามระยะ (destination point) แล้วหาตำบลด้วย point-in-polygon
   - ระยะหน้าไฟ = ระยะที่หัวไฟเคลื่อนไป ระยะปลายกรวยควัน = ระยะควันค่าเดียวกับที่แสดงในการ์ดสถิติ (ใช้ค่าเดียวกันทั้งสองที่)
10. ปุ่มข้อความขีดเส้นใต้จัดกลาง "ข้อสมการและหลักการวิทยาศาสตร์" กดกาง/พับ เมื่อกางเป็นการ์ดพื้นครีมอ่อน 5 ข้อ เลขข้อและชื่อสมการตัวหนา สูตรเป็น inline code (monospace พื้นเทา) ค่าในสูตรแทนด้วยค่าจริงของจุดนั้น (ตัวเลขด้านล่างเป็นตัวอย่างจากต้นแบบ):
    - **1. ความชื้นสมดุลเชื้อเพลิง (Simard 1968 EMC):** คำนวณการดูดซับความชื้นของเศษไม้แห้งจากอุณหภูมิ (32.3 °C) และความชื้นสัมพัทธ์ (61%) ได้ `EMC = 11.6%` และตัวคูณลดทอนความชื้น `η_M = 1.43`
    - **2. อัตราการลุกลามไฟผิวดิน (Rothermel 1972):** `R = R₀ · η_M · (1 + φ_W + φ_S)` ปรับความเร็วลมด้วยค่าบังลมของป่า (WAF = 0.3) และความชัน 4° ได้อัตราไฟลามหัวไฟ 4.7 ม./นาที ข้างไฟ 2.6 ม./นาที และท้ายไฟ 1.4 ม./นาที
    - **3. เรขาคณิตวงรีไฟป่า (Anderson 1983):** `L/B = 0.936·e^(0.2566·U) + 0.461·e^(-0.1548·U) - 0.397 = 1.2` (U = ความเร็วลมกลางเปลวไฟ ม./วินาที = ลมที่ 10 ม. x WAF)
    - **4. ความรุนแรงหน้าไฟและเปลวไฟ (Byram 1959):** `I_B = H · w · r = 746 kW/m` (H = 18,600 kJ/kg) และความสูงเปลวไฟ `L_f = 0.0775 · I_B^0.46 = 1.6 ม.`
    - **5. การปลดปล่อยมลพิษและกรวยควัน (Seiler & Crutzen 1980 / Gaussian Plume):** คำนวณจากมวลชีวมวลที่เผาไหม้จริง x สัมประสิทธิ์ปลดปล่อยของป่าเบญจพรรณ (`EF_PM2.5 = 10.5 g/kg`, `EF_CO₂ = 1590 g/kg`)
11. คำเตือนตัวเล็กใต้การ์ด: "ผลจำลองเป็นค่าประมาณจากแบบจำลอง ไม่ใช่ข้อมูลทางการ ห้ามใช้เป็นเกณฑ์เดียวในการตัดสินใจภาคสนาม"

### 7.4 ฝุ่น PM2.5 / AQI ของจุดนั้น (ในแผงเดียวกัน ต่อจากหัวข้อ 7.2)

### 7.5 สภาพอากาศตอนนี้ (ในแผงเดียวกัน)

- หัวใหญ่ "สภาพอากาศตอนนี้"

  - ประโยคอธิบายระดับ เช่น "ความชื้นในอากาศและเชื้อเพลิงสูง โอกาสเกิดและลุกลามของไฟป่าต่ำ"

- ถ้า API ใดเรียกจากเบราว์เซอร์ตรงๆ ไม่ได้ (CORS หรือต้องมี key) ให้เว้นจุดต่อ proxy ไว้และอธิบายวิธีตั้งค่า

## 9. ข้อมูลตัวอย่างสำหรับเฟสแรก

- จุดความร้อนประมาณ 20 จุด กระจายตัวอยู่ทั่วทั้งผืนป่า แต่ละจุดมี: พิกัด เวลาตรวจพบ ดาวเทียม FRP ความเชื่อมั่น
- สถานีฝุ่นในพื้นที่ ค่า PM2.5 สมจริง
- แต่ละจุดต้องมีชนิดป่า ความชัน ความสูง เพื่อป้อนสมการในหัวข้อ 7

---

## 10. มือถือและการเข้าถึง

- จอกว้าง < 768px: แผงซ้ายและแผงขวากลายเป็น bottom sheet (ลากขึ้นลง) ปุ่มควบคุมชิดขวาล่างเหนือ safe-area
- ปุ่มทุกอันมี aria-label ภาษาไทย ใช้งานด้วยคีย์บอร์ดได้ กดปุ่ม "/" โฟกัสช่องค้นหา กด Esc ปิดแผง/modal
- ขนาดแตะต่ำสุด 40px สีตัวหนังสือมี contrast เพียงพอ
- เคารพ prefers-reduced-motion (ปิดอนิเมชันลมและการบินกล้อง)

## 11. Modal และฟีเจอร์ที่ยังไม่มีภาพต้นแบบ (placeholder ก่อน)

ทำเป็น modal/แผงเรียบง่ายมีหัวข้อและเนื้อหาสั้นๆ พร้อมโครงให้ขยายภายหลัง:

- **"เรียนรู้ชนิดป่า":** ตารางชนิดป่า 12 ชนิดใน 6 ภาค พร้อมสี ชนิดไฟ ช่วงเกิดไฟ เชื้อเพลิงหลัก (เนื้อหาตัวอย่างสมเหตุสมผล)
- **"วิเคราะห์สถิติย้อนหลัง":** สรุปสถิติจุดความร้อนตามจังหวัด/ภาค/ชนิดป่า เป็นกราฟแท่งและตารางง่ายๆ
- **"ย้อนดูการลามของไฟ":** แถบเวลา (slider + ปุ่มเล่น) เล่นจุดความร้อน 2 วันย้อนหลัง
- **"คู่มือการใช้งาน":** อธิบายปุ่มและชั้นข้อมูลหลักไม่เกิน 1 หน้าจอ

## 12. แผนเฟส (ทำทีละเฟส รอผมยืนยันก่อนไปเฟสต่อไป)

**เฟส 1: โครง + แผนที่ + ของที่เห็นทันที**
แผนที่ฐาน (ธรรมชาติ/เรียบ/ดาวเทียม/ละเอียด/ถนน) · โหมด 3 มิติ · แผงซ้ายบน (สถิติ ปุ่ม การ์ดรายชื่อจังหวัด+ค้นหา) · จุดความร้อนแยก 3 สีตามอายุ · ปุ่มควบคุมขวาล่าง · สเกล · attribution · แผงชั้นข้อมูลหมวดแผนที่ฐาน/จุดความร้อน/แนวเขต/น้ำและเส้นทาง

**เฟส 2: แผงรายละเอียดจุดความร้อน**
หัวข้อ 7.1-7.3 ครบ (ตัวจำลอง วงรี 3 ชั้น กรวยควัน กำลังพล พื้นที่ใต้ลม สมการ) ผ่านค่าทดสอบ 7.3

**เฟส 3: ฝุ่น ลม อากาศแห้ง**
สถานี AQI + legend + ชิปวัน · เส้นลม · FWI/ความชื้น/VPD + ชิปวัน · ส่วน 7.4-7.5 ในแผงรายละเอียด

**เฟส 4: ชนิดป่า ข้อมูลของสถานี นำเข้าข้อมูล modal และข้อมูลจริง**
ชั้นชนิดป่า + legend + popup · ปุ่มนำเข้าข้อมูล · modal 4 อัน · ต่อ API จริงทีละตัว

## 13. รูปแบบคำตอบทุกเฟส

1. ทำอะไรไปบ้าง

4. อะไรยังไม่ทำ
