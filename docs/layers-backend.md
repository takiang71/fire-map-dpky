# เครื่องมือวาด · Layer Manager · ระบบหลังบ้านชั้นข้อมูล

ปุ่ม **วาดและจัดการชั้นข้อมูล** (ไอคอนชั้นข้อมูลมีดินสอ ในแถวปุ่มควบคุมแผนที่) หรือลิงก์ท้ายแผงชั้นข้อมูล

## ใช้งาน (ทุกคน ไม่ต้องติดตั้งอะไร)

- **ปักหมุด / เส้นทาง / รูปหลายเหลี่ยม**
  - เมาส์: คลิกวางจุด · ดับเบิลคลิกหรือ Enter = จบ · คลิกจุดที่ 1 = ปิดรูป · Backspace = ย้อนจุด · Esc = เลิก
  - จอสัมผัส: เลื่อนแผนที่ให้กากบาทตรงตำแหน่ง แล้วกด **+ เพิ่มจุด** (แตะบนแผนที่ก็ได้)
  - จบแล้วกรอก ชื่อ / รายละเอียด / สี / ข้อมูลเพิ่มเติม แล้วกด **บันทึก**
  - ก่อนบันทึก: ลากจุดเพื่อย้าย · ลากหรือคลิกจุดเล็กกลางเส้นเพื่อเพิ่มจุด · ดับเบิลคลิกจุดเพื่อลบ
  - แสดงความยาว (ม./กม.) พื้นที่ (ไร่-งาน-ตร.ว.) และพิกัด UTM ระหว่างวาด
- **แตะวัตถุบนแผนที่** = ดูรายละเอียด ระยะ/พื้นที่ แก้ไข ลบ คัดลอกพิกัด นำทาง
  - พื้นที่จะขึ้นเป็นบรรทัดบนสุดของป๊อปอัปตำแหน่ง (ไม่บังข้อมูลอากาศ/ตำบล)
- **ชั้นในเครื่อง** เก็บในเบราว์เซอร์นั้นเท่านั้น (IndexedDB) — ล้างข้อมูลเบราว์เซอร์แล้วหาย ควรส่งออกเก็บไว้
- **นำเข้า** (ปุ่มนำเข้าไฟล์ หรือลากไฟล์มาวางที่แผง เลือกหลายไฟล์พร้อมกันได้)
  - GeoJSON · Esri JSON · KML/KMZ (คงสีและโฟลเดอร์) · GPX · CSV · Shapefile (.zip หรือเลือก .shp .dbf .prj .cpg พร้อมกัน)
  - CSV อ่านคอลัมน์ ละติจูด/ลองจิจูด (lat/lon, องศาลิปดาฟิลิปดาได้) · UTM (x/y, easting/northing + คอลัมน์โซน ไม่มี = 47) · WKT
  - ระบบพิกัด: WGS84, UTM WGS84 ทุกโซน, Indian 1975 UTM 47/48 (แปลงด้วยค่ากรมแผนที่ทหาร 204.4798, 837.8940, 294.7765), Web Mercator · ระบบอื่นใน .prj โหลด proj4 จาก cdnjs มาแปลง
  - ไม่มี .prj แต่ค่าพิกัดเป็นเมตร = ถือว่าเป็น UTM 47N (แจ้งเตือนในผลการนำเข้า)
  - .dbf ภาษาไทยอ่านตาม .cpg หรือเดา UTF-8 / TIS-620 ให้
- **ส่งออก** (ปุ่มส่งออก… หรือเมนู ⋯ ของชั้น) เลือกได้หลายชั้น
  - KMZ / KML (หลายชั้น = แยกโฟลเดอร์ คงสี)
  - Shapefile .zip — แยกไฟล์ตามชนิด จุด/เส้น/พื้นที่ · WGS84 หรือ UTM 47N/48N · UTF-8 + .cpg
    - DBF จำกัดชื่อคอลัมน์ 10 ไบต์ (ภาษาไทยได้ ~3 ตัว) — ถ้าถูกตัดจะมีไฟล์ `ชื่อคอลัมน์เต็ม.txt` ใน zip
  - GeoJSON · GPX (หมุด = waypoint, เส้น/ขอบพื้นที่ = track) · CSV (Excel, มีคอลัมน์ WKT)

## ติดตั้งระบบหลังบ้าน (ครั้งเดียว ฟรี — Cloudflare Worker + KV)

ใช้บัญชี Cloudflare เดิม (บัญชีเดียวกับ Worker ของ LINE bot)

1. Cloudflare → **Workers & Pages → Create → Create Worker**
   - ตั้งชื่อ **`fire-layers`** (เว็บเรียก `https://fire-layers.takiang71.workers.dev` — ถ้าใช้ชื่ออื่นต้องแก้ `UL_API` ใน index.html)
   - กด Deploy → **Edit code** → ลบโค้ดเดิม วางทั้งไฟล์ `worker/layers.mjs` → **Deploy**
2. **Storage & Databases → KV → Create** ตั้งชื่อ `fire-layers`
3. เปิด Worker `fire-layers` → **Settings → Bindings → Add → KV namespace**
   - Variable name: **`LAYERS`** · KV namespace: `fire-layers` → Deploy
4. **Settings → Variables and Secrets → Add**
   - Type: **Secret** · Name: **`ADMIN_PASS`** · Value: รหัสผ่านผู้ดูแลหลัก (ยาวๆ เดายาก) → Deploy
5. ตรวจ: เปิด `https://fire-layers.takiang71.workers.dev/` ต้องเห็น `{"ok":true,...,"kv":true,"admin":true}`
6. ที่หน้าเว็บ: แผงเครื่องมือ → **เข้าสู่ระบบ** ชื่อผู้ใช้ `admin` + รหัสจากข้อ 4 → **จัดการหลังบ้าน**

## หลังบ้าน (ผู้ดูแล)

- **กลุ่ม**: สร้างกลุ่ม เช่น "สถานีควบคุมไฟป่าทับลาน"
- **ผู้ใช้**: ชื่อผู้ใช้ (a-z 0-9 _ . -) + รหัสผ่าน ≥ 8 ตัว + กลุ่ม · ติ๊ก "ผู้ดูแล" ให้จัดการหลังบ้านได้
  - **ปิดใช้งาน** = เข้าไม่ได้ทันที · ตั้งรหัสใหม่ให้ได้ · ผู้ใช้เปลี่ยนรหัสเองได้ (เมนูเปลี่ยนรหัสผ่าน)
- **ชั้นข้อมูล**: วาด/นำเข้าเป็นชั้นในเครื่องก่อน → **+ อัปโหลดชั้นในเครื่องขึ้นเซิร์ฟเวอร์** (หรือเมนู ⋯ ของชั้น)
  - ใครเห็น: **ทุกคน** (ไม่ต้องล็อกอิน = เปิดเผยสาธารณะ) / **ทุกคนที่เข้าสู่ระบบ** / **เฉพาะกลุ่มหรือผู้ใช้ที่เลือก**
  - เปิดแสดงเป็นค่าเริ่มต้น · อนุญาตให้ส่งออก/คัดลอก
  - แก้ข้อมูลชั้นบนเซิร์ฟเวอร์: เมนู ⋯ → **คัดลอกลงเครื่อง** → แก้ → เมนู ⋯ ของชั้นในเครื่อง → **อัปเดตชั้นบนเซิร์ฟเวอร์**
- ผู้ดูแลหลัก `admin` ไม่อยู่ในรายชื่อผู้ใช้ เปลี่ยนรหัสได้ที่ Secret `ADMIN_PASS` เท่านั้น (เปลี่ยนแล้ว token เดิมของ admin ใช้ไม่ได้)

## ข้อจำกัด / ความปลอดภัย

- โควตาฟรี: Worker 100,000 คำขอ/วัน · KV อ่าน 100,000/วัน เขียน 1,000/วัน พื้นที่ 1 GB
  - เปิดหน้าเว็บ 1 ครั้ง = อ่าน KV 1 ครั้ง (+1 ต่อชั้นที่เปิด) · การเขียนเกิดเฉพาะตอนผู้ดูแลแก้
- ชั้นละไม่เกิน 20 MB (GeoJSON)
- KV อาจใช้เวลาถึง ~60 วินาทีกว่าการแก้ไขจะเห็นทุกที่
- ข้อมูลชั้นเก็บใน KV ไม่อยู่ใน repo สาธารณะ · ชั้น "เฉพาะกลุ่ม" ดาวน์โหลดได้เฉพาะผู้มี token ที่ถูกต้อง
- รหัสผ่านเก็บแบบ PBKDF2-SHA256 + salt · token อายุ 30 วัน · ใส่รหัสผิด 8 ครั้ง = ล็อก 15 นาที
- ชั้นที่ตั้ง "ทุกคน" ใครก็ดาวน์โหลดได้ — ห้ามใช้กับข้อมูลลับ
