### E. ความปลอดภัย

#### E1 (กลาง) สคริปต์จาก CDN ไม่มี `integrity`/`crossorigin`
- **หลักฐาน**: maplibre 4.7.1 (cdnjs), proj4 2.11.0 โหลดเมื่อต้องใช้ — `integrity=` 0 แห่ง
- **ขั้นตอน**: คำนวณ sha384 ของไฟล์ที่ใช้ (ดาวน์โหลดแล้ว `openssl dgst -sha384 -binary | base64`) ใส่ `integrity` + `crossorigin="anonymous"` ทุก `<script src>`/`<link>` ภายนอก รวมในคู่มือ · ทางเลือกดีกว่า: self-host ใน `vendor/` (ช่วย D1 ด้วย) และอัปเกรด MapLibre เป็นรุ่นล่าสุดหลังทดสอบ (ตรวจ breaking changes `setTerrain`, `addProtocol`, `cooperativeGestures`)
- **ตรวจรับ**: ไม่มี error SRI ใน console · check_site ผ่าน

#### E2 (กลาง) ตรวจ XSS อัตโนมัติ + CSP แบบรายงานอย่างเดียว
- **หลักฐาน**: `innerHTML` 186 แห่ง, `esc()` 436 — ครอบคลุมดีแต่ไม่มีตัวตรวจอัตโนมัติ; ข้อมูลภายนอกที่เข้าหน้าเว็บ: API (ชื่อตำบล), Power BI, KML description/ExtendedData ของผู้ใช้, ชั้นเซิร์ฟเวอร์ที่ผู้ดูแลอัปโหลด
- **ขั้นตอน**: (1) สคริปต์ `scripts/lint_html.js` หา template literal ที่มี `${...}` ภายใน `innerHTML=`/`insertAdjacentHTML`/`new maplibregl.Popup().setHTML` แล้วตัวแปรไม่ผ่าน `esc(`/`Number(`/ตัวเลขชัดเจน → รายงาน (ใส่ใน check_site เป็นคำเตือน) (2) ทดสอบด้วยไฟล์ KML ที่ชื่อ/คำอธิบายเป็น `<img src=x onerror=alert(1)>` ผ่าน GIO.load → ต้องแสดงเป็นข้อความ (3) เพิ่ม `<meta http-equiv="Content-Security-Policy-Report-Only">` รายชื่อโดเมนจาก `grep -o "https://[a-z0-9.-]*" index.html` แล้วดู violation ใน console 1 สัปดาห์ก่อนบังคับ

#### E3 (ต่ำ) หลังบ้านชั้นข้อมูล (fire-layers Worker)
- **ขั้นตอน**: จำกัดขนาด body อัปโหลด (เช่น 8 MB; KV สูงสุด 25 MB) ตอบ 413 · เพิ่ม endpoint "ออกจากระบบทุกอุปกรณ์" (bump `v` ของผู้ใช้เอง) · บันทึก audit log ย่อ (ใคร อัปโหลด/ลบ ชั้นใด เมื่อไร) ใน KV `log` 200 รายการ แสดงในแท็บผู้ดูแล · ทดสอบกับ mockworker เดิม (docs/layers-backend.md) · **ผู้ใช้ต้องวางโค้ด Worker ใหม่เอง**

## 6. สิ่งที่ตรวจไม่ได้ในรอบนี้ (ข้อจำกัดของการตรวจ)

- ไม่ได้ทดสอบบนมือถือ/แท็บเล็ตจริง, LINE/Telegram จริง, เครื่องพิมพ์, QGIS (ดู D7)
- ไม่ได้วัดเวลาโหลดจริงบนเครือข่ายมือถือ (ตัวเลขขนาดไฟล์มาจากการวัดในเครื่อง)
- ไม่ได้ตรวจโค้ด Worker ที่ deploy บน Cloudflare ว่าตรงกับ `worker/*.mjs` ใน repo (ตรวจได้แค่หน้าสถานะตอบปกติ) — ผู้ใช้ควรยืนยันว่าวางโค้ดรุ่นล่าสุดแล้ว (`worker/line-webhook.mjs` คำสั่ง "เผาไหม้/เฝ้าระวัง/รหัสผู้ใช้")
- ไม่ได้ตรวจความถูกต้องเชิงป่าไม้ของเนื้อหาหน้าข้อมูลพื้นฐาน (ประวัติ/สัตว์ป่า/ตัวเลข UNESCO) — ควรให้ผู้ใช้หรือนักวิชาการตรวจทาน
