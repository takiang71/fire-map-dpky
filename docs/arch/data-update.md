# การอัปเดตข้อมูลที่ต้องทำด้วยมือ

> เพิ่ม 15 พ.ย. 69 ตามข้อ C1 ขั้น 3 ของ [docs/review-2569-11-15.md](../review-2569-11-15.md) — ดัชนีอยู่ที่ [CLAUDE.md](../../CLAUDE.md)

## Excel จุดความร้อนกรมอุทยานฯ ปีงบใหม่ (ทำปีละครั้ง หลังกรมอุทยานฯ ส่งไฟล์ปีงบที่จบแล้ว)

**ทำไมต้องทำ**: การ์ดหลัก (เทียบปีงบก่อน), แผงสถิติย้อนหลัง, ตาราง/รายงานช่วง "ปีงบก่อน" ใช้ข้อมูลกรมอุทยานฯ (`hdata` ใน index.html) เป็นตัวเลขทางการ
- ระหว่างที่ยังไม่นำเข้า หน้าเว็บ**เติมปีงบที่ขาดจาก API ให้เอง** (`hdFill` — จุดดาวเทียมตัวชี้วัดทุกจุดในแนวเขต, ld "ไม่มีข้อมูลประเภทพื้นที่") และติดป้าย "⚠ ปีงบ 25xx ใช้จุดจาก API (ยังไม่มีข้อมูลกรมอุทยานฯ)" — ตัวเลขจึงไม่เป็น 0 แต่ไม่ใช่ตัวเลขทางการ
- health รายการ `xlsx` แจ้งผู้ดูแลทาง LINE/Telegram เดือนละครั้งตั้งแต่ 1 ธ.ค. ของปีงบถัดไป ถ้า hdata ยังถึงแค่ปีงบก่อนหน้านั้น
- ปีที่มีใน Excel แม้จุดเดียว = ไม่เติมจาก API อีก (ยึด Excel) → นำเข้าครั้งเดียวป้ายหายเอง

**ขั้นตอน** (ในเครื่องผู้ดูแล โฟลเดอร์โปรเจกต์ · ต้องได้รับอนุญาตจากผู้ใช้ก่อนแก้ hdata ทุกครั้ง — กติกาข้อ 3 ของ CLAUDE.md)

1. `git pull`
2. วางไฟล์ Excel ฉบับใหม่ที่ `data/` (ฉบับเดิม `data/Data_hotspots_61-69_DPYK_Full2.xlsx` — ไฟล์ใหม่ต้องมี**ทุกปีงบ** 2561 → ปีล่าสุด ในชีตเดียวกัน คอลัมน์แบบเดิม เพราะสคริปต์แทน hdata ทั้งก้อน)
3. `node scripts/excel_to_hdata.js data/<ไฟล์ใหม่>.xlsx` → แก้บล็อก `hdata` ใน index.html (คงลำดับ dictionary เดิม) · ดูจำนวนจุดต่อปีงบที่สคริปต์พิมพ์ เทียบกับตัวเลขของกรมอุทยานฯ
4. `node scripts/sync_hotspots.js` → จับคู่ `dnp` + CSV เทียบ API ใหม่
5. `node --test test/` และ `node scripts/check_site.js` ต้องได้ `✅ ผ่าน`
6. เปิดหน้าเว็บ (`node scripts/serve.js`) ตรวจ: การ์ด "เทียบปีงบประมาณ" ไม่มีป้าย ⚠ แล้ว · แผงสถิติย้อนหลังมีปีงบใหม่ · ปีงบใหม่ในการ์ด = จำนวนจุดที่ไม่ใช่ "การจัดการเชื้อเพลิง/ตรวจสอบแล้วไม่พบไฟ"
7. แก้ตัวเลขในเอกสารที่อ้างจำนวนจุด (data-blocks.md "ปีงบ 2569 = 133 จุด" ฯลฯ, คู่มือหมวดข้อมูลย้อนหลัง) แล้ว commit + push (`git add index.html data/<ไฟล์>.xlsx data/ docs/ manual/`)
8. รอบ site ถัดไป health `xlsx` จะแจ้ง "กลับมาปกติแล้ว"

**ไฟล์ที่เกี่ยวข้อง**: `scripts/excel_to_hdata.js` (อ่านด้วย `scripts/lib/xlsx.js`), `hdFill`/`hdfNote` ใน index.html, `chkXlsx` ใน `scripts/health.js`, เทสต์ `test/hdfill.test.js` (จำลอง 2 ต.ค. 2570) และ `test/health.test.js`
