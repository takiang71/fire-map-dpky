# บล็อกข้อมูลฝังใน index.html และไฟล์ข้อมูลหลัก

> โครงสร้าง `geo` `hdata` `adata` `fxdata` `wdata` `wadata` + สคริปต์นำเข้า + กติกาการใช้ HD/AD/ตัวชี้วัด/ดาวเทียม/ดงใหญ่ในหน้าเว็บ
> ย้ายมาจาก CLAUDE.md เดิม (15 พ.ย. 69) โดยไม่ตัดข้อเท็จจริง — ดัชนีอยู่ที่ [CLAUDE.md](../../CLAUDE.md)

## บล็อกข้อมูลใน index.html

- `index.html` — ทั้งแอป (CSS + HTML + JS) ข้อมูลฝังเป็น `<script type="application/json">` 2 บล็อก
  - `id="geo"` แนวเขตจริง `{cons, resp, stn, wpt}` (GeoJSON) — สร้างจาก KMZ · `wpt` = จุดเฝ้าระวังไฟป่า ปี 2569 (47 จุด, props: name รหัสจุด เช่น ขญ.1, station, loc, ftype, vil, moo, tam, amp, prov, utm)
  - `id="hdata"` จุดความร้อนย้อนหลัง เข้ารหัส dictionary: `{pv,am,tm,ar,ld,fu,st,sb, r:[[day,hhmm,lat*1e5,lon*1e5,pv,am,tm,ar,ld,fu,st,sb],…]}`
    - `day` = วันนับจาก 1970-01-01 (UTC), `tm` = "ตำบล|อำเภอ", `ld` = ประเภทป่าในพื้นที่อนุรักษ์, `fu` = การจัดการเชื้อเพลิง
  - `id="adata"` จุดสะสมจาก API (สร้างโดย `scripts/sync_hotspots.js` ห้ามแก้มือ): `{v,upd,from,api0,to,sat,cf,pv,am,tm,ar,st,sb, r:[[day,hhmm,lat*1e5,lon*1e5,sat,cf,pv,am,tm,ar,st,sb,dnp(,1=NASA FIRMS)]]}` ทุกดาวเทียม เฉพาะในแนวเขต
    · **ตั้งแต่ 11 พ.ย. 69 ครอบปีงบ 2561 เป็นต้นไป** (ผู้ใช้ขอ "ย้อนไปจนถึงปี 61"): `from` = 2017-10-01 (วันแรกของทั้งชุด), `api0` = 2024-08-03 (วันแรกที่ API ไทยมีข้อมูล — ก่อนหน้านั้น API ตอบว่างทุกวัน)
    · ก่อน api0 = NASA FIRMS จาก `data/hotspots_hist.json` (ช่องท้าย 1)
    · `dnp=1` = จุดเดียวกับข้อมูลกรมอุทยานฯ (จับคู่ 1:1 เฉพาะ SNPP วันเดียวกัน ±10 นาที <400 ม.)
    · `to` = วันสุดท้ายที่ดึงครบ
- `id="fxdata"` **ข้อมูลการดับไฟป่า** (ผู้ใช้ขอ 5 พ.ย. 69 จากไฟล์ `D:งานไฟป่า-เกรียงไกรสถิติไฟป่าhotspotข้อมูลดับไฟป่า ปี 2564 - 2568_อสข้อมูลดับไฟป่า ปี2564-2568-ตัด.xlsx` = สถิติดับไฟรวม อส. ตัดเฉพาะกลุ่มป่า 294 แถว) สร้างโดย `node scripts/import_fx.js <xlsx>` (ห้ามแก้มือ): `{src,upd,q:{fixed,none,mis,out},pv,am,tm,ar,st,sb,cs,rp,fr, r:[[day,hhmm รับแจ้ง,lat*1e5,lon*1e5,xy,pv,am(อำเภอ|จังหวัด),tm(ตำบล|อำเภอ|จังหวัด),ar(ตามพิกัด where()),st(ช่อง ดำเนินการโดย),sb(SBP ตามจังหวัด),ไร่,cs,rp,fr(พื้นที่ป่าตามรายงาน),hhmm เข้าดับ,hhmm เสร็จ,E,N,หมู่,สถานที่,รายละเอียดสาเหตุ,ลำดับต้นฉบับ,ผู้ดำเนินการ(ข้อความเต็ม),(ตรวจแล้ว=1 เฉพาะแถวที่ Excel มีคอลัมน์ "ตรวจแล้ว")]]}` · `q.ck` = จำนวนแถวที่ตรวจแล้ว (มีเฉพาะเมื่อ >0; C4 16 พ.ย. 69 → [data-update.md](data-update.md))

  · คงในโค้ดหลัก (ทุกเครื่องใช้): `SY` `SYMSG` `syAdm` `syGate` `syFlags` `syHide` `syAnn` `syAnnPos` `syHit` และ `ulPublish` `ulLogAll` `ulPw` ฯลฯ
- **ตัวโหลด** (สคริปต์แอปตัวแรก ถัดจาก `embGet`): `lzJs(n)` คืน Promise แคชต่อชื่อ (ล้ม = ลบแคช เรียกใหม่ได้)
  · มีบล็อก `#lz-<n>` (repo) = สร้าง `<script>` จากข้อความ รันทันที
  · ไม่มี (_site) = `<script src>` ตามดัชนี `#lzix` (path สัมพัทธ์ — _site แบบ file:// ก็ได้) · เกิน `FTO.big` หรือ onerror = reject
  · `lzCall(n,f,a)` ตัวกลางของ **สตับ**: `function ulAdmin(...a){return lzCall('adm','ulAdmin',a)}` ในโค้ดหลัก → โหลดบล็อก → บล็อกประกาศ `async function ulAdmin` ชื่อเดิม **ทับสตับ** (function ระดับบนสุดของ classic script ทับกันได้) → เรียกตัวจริง · โหลดไม่ได้ = `dbg('lzJs adm')` + toast "โหลดส่วนหลังบ้านไม่ได้ (ออฟไลน์) — ตรวจการเชื่อมต่ออินเทอร์เน็ต แล้วลองใหม่หรือรีโหลดหน้า" (`LZN` ชื่อภาษาไทยของแต่ละบล็อก) · บล็อกไม่ทับสตับ = แจ้งแบบเดียวกัน ไม่วนเรียกตัวเอง · error จากฟังก์ชันจริงส่งต่อผู้เรียกตามเดิม
- **กติกาบล็อก lazy** (test/lazy.test.js ตรวจ): โค้ดหลัก**ห้ามอ้างชื่อที่อยู่ในบล็อกตรง ๆ** (ยังไม่โหลดตอนเปิดหน้า) — ต้องเป็นสตับ `lzCall` หรือ `await lzJs('<n>')` ก่อน · บล็อกห้ามประกาศ `const`/`let` ชื่อที่โค้ดหลักมี (SyntaxError ตอนโหลด) · ฟังก์ชันชื่อเดียวกับโค้ดหลักได้เฉพาะสตับ · บล็อกไม่ใช่ strict (เหมือนสคริปต์ UL เดิม) · ห้ามมี `</script>` ในโค้ด
- **build_site.js `splitLz(html, OUT)`** (หลัง `splitEmb`): บล็อก → `_site/js/<n>.<sha8>.js` (เนื้อหาเดิมทุกไบต์, ลบโฟลเดอร์ js/ เก่าทุกครั้ง) + `<script type="application/json" id="lzix">{n:url}</script>` ที่ตำแหน่งบล็อกแรก · ไล่แท็กระดับบนสุดแบบ splitEmb (สตริง "<script" ในโค้ด/หมายเหตุไม่ถูกนับ)

- **ตัวตรวจ**: `check_site` syntax คอมไพล์บล็อก `text/x-lazy` (repo) และไฟล์ตาม `#lzix` (_site — ไม่มีไฟล์ = ไม่ผ่าน) · `--ci` ไม่ผ่านแล้วใช้ index.html บนเว็บ = ดึงไฟล์ js/ ตาม `#lzix` ของฉบับนั้นมาด้วย · `lint_html` ตรวจบล็อก x-lazy และไฟล์ js/ ตาม `#lzix` (คีย์ base เดิม `app` — ผล 338 จุดเท่าเดิมทั้ง repo และ _site) · ขั้น `E3UI` กด `ulAdmin` ผ่านสตับ (ทางเดียวกับผู้ใช้) แล้วตรวจว่า `ulALog` มา · `SYUI` `await lzJs('adm')` ก่อน
