  · **สวิตช์ `#h-sp` "แสดงจุด"** (`.hsp` เล็ก) หน้าปุ่มซูมบนหัวการ์ดสถิติ ใช้ร่วม 3 โหมด ค่าเริ่มต้นเปิด (ผู้ใช้ขอ 6 พ.ย. 69 — รอบแรกเป็นแถวในการ์ด จปร. ค่าเริ่มต้นปิด แล้วผู้ใช้ให้ย้าย+เปิด): hs → S.hist / xt → S.xt (จำใน `HSP` ให้ hTab ใช้ค่าที่เลือก, sync() อัปเดตเมื่อสลับจากแผงชั้นข้อมูล) / wa → `S.wsp` (LW แสดง wt-* เมื่อ S.wst&&S.wsp)

  · **จุดพื้นที่เฝ้าระวังมีผลกับฟังก์ชันจุดความร้อนอื่น** (ผู้ใช้ขอ 7 พ.ย. 69 — ผู้ใช้แจ้งกองจุดความร้อน/เล่นย้อนไม่รวม จปร.): hcPts เพิ่มจุด WR เมื่อ S.wch (ตามปุ่มดาวเทียม, "N"=เปิดเสมอ, คีย์แคชรวม S.wch/WR.length)

  · ชื่อหมวดชั้นข้อมูล "พื้นที่เฝ้าระวังพิเศษ"
  · เส้นแนวเขตสีเหลือง #f5c400 กว้าง 1.8 เท่าเส้นพื้นที่อนุรักษ์ ไม่มีเส้นประ/ขอบเข้ม (ลบ wch-c)
  · `#w-ins` ใช้ CSS เดียวกับ #h-ins (เดิมตัวอักษรใหญ่)
  · **เมนู "ความสำคัญ" เปลี่ยนชื่อเป็น "ข้อมูลพื้นฐาน"** (หัวหน้า #kb-t "ข้อมูลพื้นฐานของผืนป่า"; การ์ดภายในยังชื่อ ความสำคัญของพื้นที่) — คู่มือแก้ตามแล้ว + ถ่ายภาพ overview/mobile/know/sw_wch/stats_wa ใหม่

## เทียบปีงบด้วย NOAA-20 / ข้อมูลย้อนหลังทุกดาวเทียม

- **เทียบปีงบด้วย NOAA-20 ทุกปี** (ผู้ใช้สั่ง 11 พ.ย. 69 "ทำเลย" ต่อจากข้อเสนอหลังเก็บ FIRMS ย้อนหลัง): ปุ่ม `#p-cs` ใต้หัว "เทียบปีงบประมาณ" ในการ์ดหลัก กรมอุทยานฯ (Suomi NPP — ค่าเริ่มต้น) | NOAA-20 ทุกปี
  · `CSRC` (ไม่บันทึก)
  · `fyCumSat`/`fyNowSat`/`pHistSat` จาก AD ตาม `xAD` (ไม่มี fuOK)
  · ปีที่ใช้ = ปีงบที่เริ่มหลัง `N20_0` 1 เม.ย. 61 (2562 เป็นต้นไป)
  · PCH แคชรวม `c`
  · renderCard: ไทล์สะสมยังใช้ `now` (ตัวชี้วัด) ส่วนแท่งเทียบ/กล่องทั้งปี/กราฟใช้ `cn`
  · ปีงบ 2569 ทั้งปี NOAA-20 = 113 (ไม่รวมดงใหญ่) vs กรมอุทยานฯ 83
  · รายการแท็บ "เทียบปีงบก่อน" ยังเป็นกรมอุทยานฯ
